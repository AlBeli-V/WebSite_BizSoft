# Модуль CRM

Работа с заявками: воронка, регламент менеджера, письма клиенту, напоминания.

## Граница с сайтом

CRM — независимая опция. Витрина о ней не знает и не должна знать.

- Код: `src/crm/` (правила и тексты), `src/pages/admin/` (интерфейс),
  `src/pages/api/admin/` (API).
- Данные: коллекции `leads` и `lead_events` в Directus.
- Единственная точка соприкосновения — форма заявки `src/pages/api/lead.ts`:
  она кладёт запись в `leads` со стадией `new`. Больше ничего общего нет.

Граница проверяется тестом `tests/crm-isolation.test.ts`: витрина не имеет
права импортировать что-либо из `src/crm`, а сам модуль — обращаться к DOM,
делать сетевые вызовы и тянуть `src/lib` сайта. Проверка механическая, потому
что словами такую границу не удержать.

**Как убрать CRM целиком.** Удалить `src/crm/`, `src/pages/admin/`,
`src/pages/api/admin/`, `tests/crm-*.test.ts` и строку `status: 'new'` в
`api/lead.ts`. Сайт продолжит работать без других правок.

## Из чего состоит

| Файл | Что внутри |
|---|---|
| `stages.ts` | стадии, регламент, сроки реакции, обязательные поля, подсказки |
| `templates.ts` | шаблоны писем клиенту с подстановкой сути обращения |
| `ics.ts` | файл напоминания для календаря телефона |

Всё это — данные и чистые функции: ни запросов, ни разметки. Поэтому правила
проверяются тестами, а не глазами на проде.

## Почему так, а не иначе

**Регламент отдельно от интерфейса.** Стадии, сроки и обязательные поля
описаны один раз в `stages.ts`; страница их только отображает, API — только
применяет. Дублирование списка стадий в двух местах — верный способ разъехаться.

**Проверка на переходе, а не при сохранении.** Иначе в воронку попадают
выигранные сделки без суммы и отказы без причины, и отчёт считает по пустоте.

**Календарь через `.ics`, а не через API календаря.** Файл открывается штатным
приложением iOS и Android: ни токенов, ни OAuth, ни зависимости от чужого
сервиса. Работает и офлайн.

**Письмо напоминает клиенту его обращение.** Дата, тема и его собственный текст
в первых строках. Безличное «здравствуйте, чем помочь» читается как рассылка и
остаётся без ответа.

**Мусор исключён из всех цифр.** Тест и спам — не обращения; если считать их в
воронке, конверсия занижается без причины. Лежат в корзине до удаления.
