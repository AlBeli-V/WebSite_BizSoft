ГРАНИЦЫ ПРОГОНА. Это операционный прогон, не сессия разработки. Запрещено: коммитить в main; изменять .github/workflows/**, CLAUDE.md, конфигурацию сборки и деплоя; изменять scripts/** и src/**; коммитить в seo-data что-либо вне reports/seo/intelligence; сливать pull request; менять настройки Routine, секреты, цены, домены, рекламные кабинеты.

Если обнаружена проблема кода или инфраструктуры — НЕ чини её: создай issue с меткой alert (симптом, доказательство, предлагаемое решение) и продолжи прогон.

1) Подготовка:
   git fetch origin main seo-data
   git checkout main && git reset --hard origin/main
   (именно reset, а не pull: историю main переписывали, и обычный pull расходится)
   bash scripts/seo/data_sync.sh pull

2) Сборка письма:
   python3 scripts/seo/committee.py <сегодняшняя дата по МСК>
   Скрипт печатает окно недели и путь письма. Код возврата 1 означает, что гейт содержания не пройден (нет обязательного блока или запрещённая формулировка) — в этом случае письмо НЕ отправляется: опиши причину в отчёте и заведи issue с меткой alert.

3) Тесты обязаны быть зелёными, иначе не пушь:
   python3 -m unittest discover -s scripts/seo/tests -t scripts/seo/tests

4) Отправка (только если шаги 2 и 3 прошли):
   bash scripts/seo/data_sync.sh push "Письмо комитета за <дата>" "reports/seo/intelligence"
   Push запускает workflow seo-committee-email.yml, который и отправляет письмо на avbelyaev@biz-soft.pro. Проверь статус run: он должен завершиться success и записать маркер last-committee-mailed.txt.

5) Короткий отчёт руководителю в чат: окно недели, что выросло и что упало, пять действий недели из allocator, вердикты экспериментов, есть ли просроченные контуры в loop-health. Если данных не хватило — скажи прямо, не заполняй пробел догадкой.
