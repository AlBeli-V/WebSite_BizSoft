# Библиотека материалов BIZSoft

Механизм накопления: где живёт навык письма, где — сами материалы и как они
переиспользуются на сайте и во внешних источниках.

## Из чего состоит

| Что | Где | Зачем |
|---|---|---|
| Навык письма | `.claude/skills/bizsoft-content/SKILL.md` | Редполитика, приёмы, принципы ценности, антипаттерны. Подхватывается автоматически при задачах «напиши статью» |
| Журнал уроков | `content-library/lessons.md` | Каждое ревью → правило. Источник пополнения навыка |
| Банк фактов | `content-library/facts.md` | Проверяемые утверждения с источником и датой. Из него берутся все факты в текстах |
| Контентные объекты | `content-library/objects/<slug>/` | Тема и все её версии под разные поверхности |
| Регламенты площадок | `docs/marketing/external/<площадка>-requirements.md` | Ограничения конкретной площадки |
| Реестр публикаций | `data/marketing/publications.json` | Что, где и когда опубликовано + замеры |
| Линтер | `scripts/marketing/lint-content.mjs` | Машинная проверка правил перед ревью |
| Сборщик Word | `scripts/marketing/build-external-docx.cjs` | Пакет на внешнее ревью |

## Контентный объект

Единица работы — не статья, а **тема**. Одна тема живёт на нескольких
поверхностях, и все версии лежат рядом:

```
objects/<slug>/
  meta.yml        — тема, ключевые фразы, целевые URL, статус, где опубликовано
  source.md       — мастер-версия: самая полная, из неё делаются адаптации
  dzen.md         — версия для Дзена
  vc.md           — версия для VC.ru
  site.md         — версия для блога сайта (с front matter Astro)
```

Правило: **адаптация делается из мастер-версии, а не из другой адаптации.**
Копия статьи с площадки на сайт (и наоборот) — потеря и для площадки, и для
сайта; поисковик видит дубль, читатель — второй раз тот же текст.

Переиспользование на сайте: мастер-версия → `site.md` с front matter →
`src/content/blog/<slug>.md`. Дальше действуют правила проекта: уникальные
title и description, sitemap, переобход через `ops-yandex-recrawl`.

## Жизненный цикл материала

1. **Тема.** Реальный вопрос покупателя — из поиска по каталогу
   (`search_no_results`), из комментариев, из вопросов клиентов, из
   семантики (`seo-wordstat`).
2. **Факты.** Собираются в `facts.md` с источником и датой.
3. **Мастер-версия.** Пишется по SKILL.md.
4. **Линтер.** `node scripts/marketing/lint-content.mjs objects/<slug>/source.md`
5. **Адаптации** под площадки по их регламентам.
6. **Внешнее ревью.** Word-пакет, замечания → `lessons.md`.
7. **Публикация.** Запись в реестр публикаций.
8. **Замеры** на 3-й, 7-й и 14-й день (индексация, показы, переходы, ссылки).
9. **Переиспользование.** Через 1–2 месяца мастер-версия дорабатывается в
   страницу сайта или в материал для другой площадки.
