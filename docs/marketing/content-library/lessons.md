# Журнал уроков ревью

Каждое внешнее ревью даёт правила. Формат записи: замечание → что сделали →
правило на будущее → где закреплено.

Закрепление: `SKILL` — навык `.claude/skills/bizsoft-content/SKILL.md`,
`LINT` — линтер `scripts/marketing/lint-content.mjs`, `REG` — регламент
площадки.
