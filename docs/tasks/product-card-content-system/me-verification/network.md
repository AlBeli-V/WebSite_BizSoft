OpManager Nexus, Applications Manager, NetFlow Analyzer, NCM, Firewall Analyzer,
OpUtils, DDI Central.

`scratchpad/me-src/data/sources/manageengine/2026-09-14/details/<id>.txt`.

## Сквозные наблюдения (касаются всех девяти страниц)

1. **Модель срока подтверждена.** На каждой странице три вкладки:
   `Annual Subscription` / `Perpetual` / `Get Quote`. В снятой вкладке подписки
   колонка AMS у каждой строки — `Included`. Формулировка профиля «годовая
   подписка: обновления и поддержка включены; бессрочная — по запросу» верна.
   Размер AMS 20 % в снимке не виден (вкладка `Perpetual` не снята) — остаётся
   по прежнему знанию.
2. **Пакеты дополнительных пользователей есть у каждого продукта** — блок
   `… Additional User Pack`, ряд 1 / 2 / 5 / 10 / 25 / Unlimited (у DDI Central —
   `Additional Admin / Operator User Pack` с тем же рядом). Это опровергает
   общую формулировку профиля «дополнительные пользователи — по запросу»
   (шапка, «Неопределённости», п. 1) для всех девяти продуктов.
   Предлагаемая формулировка: «Пользователи консоли сверх входящих в пакет
   докупаются готовыми пакетами: 1, 2, 5, 10, 25 и без ограничения числа».
3. **Услуги внедрения — отдельные позиции у каждого продукта:**
   `Onsite Training and Onboarding Assistance (2 Days)`, `Online Training
   (2 Days with 3 hours/day)`, `One-Time Migration/Upgrade Assistance`;
   у OpUtils и DDI Central дополнительно `Web-based Installation & Setup and
   Training (3hrs each for 2 days)`. В профиле услуг нет вовсе.
   Предлагаемая формулировка (общая для вендора): «Вендор продаёт отдельными
   позициями обучение и запуск: очное обучение и сопровождение внедрения (2
   дня), онлайн-обучение (2 дня по 3 часа), разовую помощь с миграцией или
   обновлением. Это услуги, а не лицензии».
4. **Скидка 20 % при покупке к OpManager подтверждена дословно** на страницах
   Applications Manager, NetFlow Analyzer, NCM, Firewall Analyzer и OpUtils:
   «If you already have OpManager, you can purchase <продукт> as an add-on to
   OpManager at 20% discount» (у Applications Manager — «as a plug-in»).
   В профиле это сказано только про APM Plug-in; правило общее для пяти
   продуктов.
5. **Состав линейки IT operations management** (левое меню всех страниц):
   OpManager Nexus, OpManager Nexus Enterprise, OpManager, OpManager Enterprise,
   NetFlow Analyzer, Network Configuration Manager, Firewall Analyzer, OpUtils,
   Applications Manager, DDI Central. Nexus и Nexus Enterprise стоят в меню
   выше OpManager — как отдельная продуктовая линия, а не как редакции.

## OpManager (Standard / Professional) · снимок 9d5e89eed14d

- **Сходится:**
  - Device-based модель дословно: «OpManager follows device-based license model
    which allows you to monitor any number of interfaces, disk volumes and
    sensors». Терминология профиля («интерфейсы, порты, диски и метрики
    устройства входят без ограничения») подтверждена.
  - Ряд пакетов Standard и Professional — ровно как в профиле:
    `10 / 25 / 50 / 100 / 250 / 500 / 1000 Devices Pack with 2 Users`.
    Два пользователя в пакете подтверждены.
  - Потолок редакций: «(For more than 1000 devices, buy Enterprise edition)» —
    подтверждает «до 1000 устройств на одном сервере».
  - Дополнения из профиля найдены все, кроме WLC: IP SLA (`Each IP SLA Monitor
    (WAN RTT / VOIP)`), Failover (`Failover - Hot Standby Engine (MSSQL and
    Remote PGSQL)`), Lite Device Add-on, NFA, NCM, Firewall, IPAM & SPM,
    Storage Monitoring, APM Plugin.
  - Состав Lite device в профиле («IP, URL, точка доступа, WAN IP, узел Network
    Path») подтверждён заголовком блока: «Lite Device Add-on (Uptime, WAN,
    Access Points, Network Paths, URLs)».
  - Экономия до 40 % на Nexus подтверждена дословно: «Save upto 40% by
    purchasing OpManager Nexus - a single, integrated solution for network,
    bandwidth, firewall, configuration, IP address & switch port management».

- **Расхождение 1 — пакеты пользователей.**
  В профиле (шапка, «Неопределённости», п. 1): «Точные пакеты пользователей
  консоли сверх двух (цена, шаг) — на витрине не заведены; формулировать
  „дополнительные пользователи — по запросу“».
  В снимке: блок `OpManager Additional User Pack`, строки `1 User Pack`,
  `2 User Pack`, `5 User Pack`, `10 User Pack`, `25 User Pack`,
  `Unlimited User Pack`.
  Правка: «В пакет входят 2 пользователя консоли. Дополнительные — готовыми
  пакетами на 1, 2, 5, 10, 25 пользователей и на неограниченное число».

- **Расхождение 2 — перечень дополнений.**
  В профиле: «Add-on — оплачиваемый модуль внутри OpManager (Failover, Lite
  devices, IP SLA, NetFlow/трафик, NCM, IPAM, SPM, Firewall, Storage, WLC)».
  В снимке WLC как отдельного дополнения нет; зато есть два, которых в профиле
  нет: `DPI - 1 Agent` и `HighPerf - Up to 100 Interfaces (Add-on)` /
  `HighPerf - More than 100 Interfaces (Add-on)` (оба — в блоке NFA).
  Правка: «Дополнения OpManager: отказоустойчивость (Failover), облегчённые
  устройства (Lite devices), тесты IP SLA, агент глубокого разбора трафика
  (DPI), анализ потоков NetFlow с режимом повышенной производительности
  (HighPerf), управление конфигурациями (NCM), межсетевые экраны, учёт
  адресов и портов (IPAM и SPM), мониторинг дисковых массивов, плагин
  Applications Manager». Упоминание WLC как отдельного дополнения снять.

- **Расхождение 3 — единица дополнения Storage.**
  В профиле дополнение названо «Storage» без единицы. В снимке единица
  явная: `Storage Monitoring Add-on for OpManager` — `10 Disks … 5000 Disks`.
  Правка: «Мониторинг хранения лицензируется по числу дисков (пакеты от 10 до
  5000)».

- **Неопределённости:**
  - № 1 (пакеты пользователей сверх двух) — **снята**: ряд 1/2/5/10/25/без
    ограничения заведён на витрине.
  - № 2 (ряд пакетов устройств 25/50/100/250/500/1000) — **снята**: ряд
    подтверждён построчно для обеих редакций.
  - № 3 (совместимая сборка OpManager для APM Plug-in) — **открыта**: номера
    сборок на странице магазина не приводятся.

- **Нового в снимке:**
  - `DPI - 1 Agent` — агент глубокого разбора пакетов, лицензируется поштучно.
  - Ряд Lite devices: 50 / 100 / 250 / 500 / 1000 / 2500 / 5000.
  - Дополнение NCM внутри OpManager идёт до 5000 устройств (сам продукт NCM —
    до 10 000), дополнение NFA — до 500 интерфейсов.
  - Дополнение Firewall внутри OpManager: 1 / 2 / 5 / 10 / 20 / 50 устройств.
  - IPAM & SPM внутри OpManager существует в двух вариантах —
    `(Professional Add-on)` и `(Management Add-on)`; это объясняет код
    `MGMT` в наших артикулах OpUtils (см. раздел OpUtils).
  - APM Plugin: ряд 10 / 25 / 50 / 100 / 250 / 500 / 750 мониторов; отдельные
    дополнения — APM Insight по языкам (Java, .NET, Node.js, PHP, Python,
    OpenTelemetry), EUM, IBM i, SharePoint, Oracle EBS, SAP, Siebel,
    WebSphere MQ, а также AppLogs (ГБ журналов в месяц) и RUM (просмотры
    страниц в месяц).
  - Утверждение профиля «в любой редакции OpManager 5 мониторов APM доступны
    по умолчанию» на странице магазина не подтверждается и не опровергается:
    младший пакет — 10 мониторов, бесплатной квоты страница не упоминает.

## OpManager Enterprise · снимок 21df4eb62c42

- **Сходится:**
  - Стартовый объём Enterprise — 250 устройств («от 250 устройств» в профиле
    верно): блок `Base Product` начинается со строки `250 Devices Pack with
    2 Users`.
  - Формулировка лицензии совпадает с профилем дословно: «The license is
    inclusive of all the interfaces, nodes or sensors in the device».
  - Два пользователя в базовом пакете; дополнения те же, что у младших
    редакций, с собственным прайсом.

- **Расхождение 1 — верхняя граница.**
  В профиле: Enterprise «до 50 000 устройств / 100 000 интерфейсов».
  В снимке ряд заканчивается на `10000 Devices Pack with 2 Users`, ниже —
  «(For more than 10000 devices, request a personalised quote)».
  Правка: «На витрине Enterprise продаётся пакетами до 10 000 устройств;
  больший объём — по индивидуальному расчёту у вендора». Цифру 50 000 без
  первоисточника в профиле не держать.

- **Расхождение 2 — ряд пакетов Enterprise в профиле не описан.**
  В снимке: 250 / 500 / 1000 / 2500 / 5000 / 10 000 устройств.
  Правка: «Ряд пакетов Enterprise: 250, 500, 1000, 2500, 5000 и 10 000
  устройств, в каждом — 2 пользователя консоли».

- **Расхождение 3 — APM Plugin у Enterprise начинается со 100 мониторов.**
  В профиле сказано «APM Plug-in — пакет мониторов (10, 25, 50…)» без
  оговорки о редакции. В снимке Enterprise: ряд 100 / 250 / 500 / 750 / 1000 /
  2000 / 5000 мониторов, пакетов на 10, 25 и 50 нет.
  Правка: «К OpManager Enterprise плагин Applications Manager продаётся
  пакетами от 100 мониторов; младшие пакеты (10–50) — только к Standard и
  Professional».

- **Неопределённости:** относятся к общей шапке, см. раздел OpManager. Отдельно
  по Enterprise новых открытых вопросов не возникло, кроме снятой верхней
  границы (см. расхождение 1).

- **Нового в снимке:**
  - Ряд Lite devices у Enterprise длиннее на ступень — до 10 000.
  - Дополнения NFA (до 2000 интерфейсов) и NCM (до 10 000 устройств) у
    Enterprise шире, чем у младших редакций.
  - AppLogs у Enterprise начинается со 100 ГБ в месяц (у младших — с 10 ГБ).

## OpManager Nexus · снимок e2f1b25b4b65

Отдельного раздела в профиле нет — Nexus упомянут двумя строками в шапке
(«объединённая лицензия OpManager + дополнения, экономия до 40 %») и строкой в
«Снято с продажи / переименования». Снимок даёт материал на полноценный раздел.

- **Сходится:**
  - Переименование подтверждено дословно: «OpManager Nexus (formerly OpManager
    Plus)». Строка профиля «OpManager Plus → OpManager Nexus» верна.
  - Наш состав пакета совпадает с витриной построчно: младшая позиция —
    `50 Devices Pack with 2 Users and 1 Firewall`, что точно отвечает нашему
    носителю `me-opmanager-nexus-50-devices-pack-with-2-users-and-1-firewall`
    (`ZOHO-LIC-OPMGRNEXUS-TEAM-1Y-PACK-50DEV2USR1FW`).
  - Дополнение «интерфейсы сбора трафика» у нас заведено как addon к пакету
    Nexus — на витрине это блок `OpManager Nexus - Flow Interfaces`
    (10 / 25 / 50 / 100 / 250 / 500 интерфейсов), то есть привязка верна.

- **Расхождение 1 — Nexus в профиле не описан как продукт.**
  В профиле Nexus — примечание внутри раздела OpManager. В снимке это
  самостоятельный продукт с собственной страницей, собственной линейкой
  пакетов, собственными дополнениями и отдельной редакцией Enterprise
  («OpManager Nexus Enterprise» в меню).
  Правка (заготовка раздела): «OpManager Nexus (прежнее название OpManager
  Plus) — объединённая платформа управления ИТ-операциями: мониторинг сети,
  трафика, межсетевых экранов, конфигураций, адресов и портов коммутаторов в
  одной лицензии. Пакет задаётся числом устройств, числом пользователей
  консоли и числом межсетевых экранов: 50 устройств / 2 пользователя / 1
  экран, 100 / 2 / 1, 250 / 3 / 2, 500 / 5 / 3, 1000 / 10 / 5».

- **Расхождение 2 — природа пакета.**
  В профиле и в семействе `ZOHO-OPMANAGER.json` Nexus описан как набор
  «OpManager + дополнения». Витрина уточняет существенное: объём пакета — это
  **общий пул**, который клиент делит сам. Цитата: «Eg.: 50 pack can be split
  as per convenience to monitor any combination of Network (Network Devices,
  Flow Interfaces, Access points, IPs & Switch ports), Server (Servers,
  Applications and Internet Services) and Storage components - with the total
  devices under Network, Server and Storage adding up to 50».
  Правка: «Объём пакета Nexus — общий пул наблюдаемых объектов. Клиент
  распределяет его сам между сетью (сетевые устройства, интерфейсы сбора
  трафика, точки доступа, IP-адреса и порты коммутаторов), серверами
  (серверы, приложения, интернет-сервисы) и хранением; сумма по трём
  направлениям равна объёму пакета».

- **Расхождение 3 — базовые 250 портов и 250 адресов входят в пакет Nexus.**
  На страницах OpManager и OpManager Enterprise блок IPAM & SPM открывается
  строкой `250 Used Switch Ports in SPM and 250 Used IP Addresses in IPAM`
  (базовая ёмкость). На странице Nexus этой строки нет: блок
  `OpManager Nexus - IPAM & SPM (Management Add-on)` начинается сразу со строки
  `Every additional 250 Used ports in Switch Port Mapper (SPM)`.
  Правка: «В пакет Nexus базовая ёмкость учёта адресов и портов уже входит;
  докупаются только дополнительные пакеты по 250 портов и по 250 адресов либо
  снятие ограничения».

- **Неопределённости:** в профиле для Nexus не заведены. Предлагается завести
  две: (1) состав модулей, входящих в базовый пакет Nexus, в разрезе редакций
  (страница перечисляет направления, но не матрицу функций); (2) отличия
  «OpManager Nexus Enterprise» от Nexus — страница в снимке не снята.

- **Нового в снимке:**
  - У Nexus есть облачная редакция: ссылка `Pricing for cloud edition`.
  - Число пользователей и межсетевых экранов растёт вместе с пакетом
    (2 / 2 / 3 / 5 / 10 пользователей и 1 / 1 / 2 / 3 / 5 экранов).
  - Отдельный блок `OpManager Nexus - Additional Firewall`
    (1 / 2 / 5 / 10 / 20 / 50 экранов).
  - Дополнений NCM и Storage на странице Nexus нет — управление конфигурациями
    входит в пакет (подтверждается сноской: «Do you want to add additional
    devices or interfaces under device monitoring/ firewall monitoring/ netflow
    monitoring/ configuration management/ IP address and switch port
    management? Write to us at sales@manageengine.com»).
  - Блок APM Plugin у Nexus содержит только дополнения (APM Insight, EUM,
    отраслевые мониторы), без пакетов мониторов — мониторы берутся из общего
    пула устройств.

## Applications Manager · снимок bf24da32fa31

- **Сходится:**
  - Две редакции — Professional и Enterprise, как в профиле.
  - Единица — монитор; в пакет входит 1 пользователь консоли: строки вида
    `10 Monitors with 1 User`. Формулировка профиля «в пакете 1» подтверждена.
  - Ряд Professional: 10 / 25 / 50 / 100 / 250 / 500 / 750 мониторов —
    совпадает с профилем («10 / 25 / 50 / 100 / 250 / 500 …»).
  - Стартовый объём Enterprise — 100 мониторов: `100 Monitors with 1 User`.
    Наш артикул `…-PACK-100MON1USR` верен, h1 витрины «10 наблюдаемых
    компонентов» ошибочен (пакета на 10 мониторов в Enterprise нет вовсе).
  - RUM — дополнение (`Applications Manager - Real User Monitor (RUM)
    Add-on`), как и сказано в профиле.
  - Скидка 20 % при наличии OpManager подтверждена дословно.

- **Расхождение 1 — отказоустойчивость в Enterprise.**
  В профиле («Неопределённости», п. 2): «Отказоустойчивость как штатная часть
  Enterprise — не проверено», а в таблице линейки Enterprise указано
  «+ управляемые серверы, отказоустойчивость».
  В снимке отказоустойчивость — платное дополнение в обеих редакциях:
  в блоке Professional — `Failover - Hot Standby Engine (MSSQL and Remote
  PGSQL)`, и отдельной строкой в блоке Enterprise — `Failover - Hot Standby
  Engine (MSSQL and Remote PGSQL)` (с собственной, более высокой ценой).
  Правка: «Отказоустойчивость (горячий резерв консоли) — платное дополнение и
  в Professional, и в Enterprise; в состав редакции она не входит». Из строки
  линейки Enterprise слово «отказоустойчивость» убрать.

- **Расхождение 2 — учёт APM Insight.**
  В профиле: «APM Insight — агент трассировки транзакций …; считается
  монитором на экземпляр приложения (не подтверждено)».
  В снимке APM Insight — отдельная позиция на каждый язык с фиксированной
  ценой, без пакетов экземпляров: `APM Insight for Java Web Transaction
  Monitoring (Add On)`, `.Net Agent`, `Node.js Agent`, `PHP Agent`,
  `Python Agent`, `OpenTelemetry`.
  Правка: «Трассировка транзакций APM Insight подключается отдельным
  дополнением на каждый язык приложения (Java, .NET, Node.js, PHP, Python,
  OpenTelemetry). Как при этом расходуются мониторы, страница магазина не
  говорит — уточнить у вендора».

- **Расхождение 3 — бесплатная редакция.**
  В профиле в линейке первой строкой стоит «Free — 5 мониторов». На странице
  магазина бесплатной редакции нет вовсе (только Professional и Enterprise).
  Правка: строку Free из таблицы линейки перенести в текст с оговоркой «по
  сайту продукта, на витрине не продаётся».

- **Неопределённости:**
  - № 1 (стартовый объём Enterprise 100 и лимит на управляемый сервер) —
    **частично снята**: старт 100 мониторов подтверждён построчно; лимит на
    управляемый сервер страница не называет — эта часть остаётся открытой.
  - № 2 (отказоустойчивость как штатная часть Enterprise) — **опровергнута**,
    см. расхождение 1.
  - № 3 (учёт APM Insight по экземплярам) — **открыта**, но уточнена:
    на витрине это дополнение на язык, не пакет экземпляров.
  - № 4 (расхождение h1 «10 наблюдаемых компонентов» и артикула 100MON) —
    **снята в пользу артикула**: младший пакет Enterprise — 100 мониторов.
    Пометку `needs_operator` по этой позиции можно снимать.

- **Нового в снимке:**
  - Ряд Enterprise: 100 / 250 / 500 / 750 / 1000 / 2000 / 5000 мониторов.
  - Дополнение AppLogs — сбор журналов, лицензируется объёмом в месяц:
    Professional 10–500 ГБ, Enterprise 100–1000 ГБ.
  - RUM лицензируется числом просмотров страниц в месяц (от 100 тыс. до
    100 млн).
  - Отраслевые дополнения: IBM i, Microsoft Office SharePoint, Oracle EBS,
    SAP, Siebel, WebSphere MQ; отдельно — End User Monitoring (EUM).

  - № 2 (состав дельты Enterprise) — **снята**: дельта названа вендором
