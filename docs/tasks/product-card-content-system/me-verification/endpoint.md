## Patch Connect Plus
Снимок `f85c9c533911.txt`.

- **Сходится:**
  - Три редакции ровно в заявленном порядке: `Patch Connect Plus Standard Edition`,
    `Patch Connect Plus Professional Edition`, `Patch Connect Plus Enterprise Edition`.
  - Единая полоса по компьютерам без деления на серверы и станции: `250 computers`,

  - Подписка и бессрочная; облачной редакции у продукта нет — согласуется с «Windows-сервер
    рядом с SCCM».
  - Ни техников, ни резервного сервера, ни языкового пакета на витрине нет — то есть отсутствие
    этих строк в профиле корректно.

    страницей с собственными редакциями и полосами.
  - Цитата: «ManageEngine Patch Connect Plus is an add-on tool that helps deploy patches to
    over 800 third party applications…».
  - Правка (терминология): «Patch Connect Plus — отдельно продаваемый продукт (nature = mono),

  - В профиле (линейка): Standard — SCCM/WSUS, Professional — + приложения и инструменты

  - Цитата: «…using your existing Microsoft System Center Configuration Manager or Intune setup,
    all from the comfort of the same console.»
  - Правка («Единицы расчёта»): «Витрина: „пакет: 250 компьютеров под управлением SCCM или
    Intune“; распределение SCCM/Intune по редакциям витриной не подтверждено — сверять по
    матрице редакций вендора».

- **Неопределённости:**
  - № 1 (дельта редакций: приложения и инструменты — Professional, Intune — Enterprise) —
    **открыта**: витрина состава редакций не раскрывает (см. расхождение 2).

    то есть у Patch Connect Plus их отсутствие — осознанная модель, а не пробел снимка.
  - № 3 (co-management и сценарий «только Intune») — **открыта.**

- **Нового в снимке:**
  - Объём каталога: «over 800 third party applications such as Adobe, Java and WinRAR».
  - Единственная дополнительная позиция — `Patch Connect Plus Training`

## Сквозные наблюдения по линейке

1. **Единый набор надстроек.** У пяти продуктов из семи витрина заводит один и тот же набор:
   дополнительные пользователи консоли (полосы 1/2/5/10/25/50), резервный сервер (failover)
   тремя полосами по числу машин, языковой пакет, обучение, шлюз Secure Gateway Server.
   В профиле этот слой не описан ни у одного продукта, кроме упоминания шлюза как функции.
   Предлагается завести в каждом разделе подраздел «Надстройки витрины» и перечислить их
   единообразно — это прямо влияет на состав коммерческого предложения.
2. **Шлюз — не признак старшей редакции.** У Patch Manager Plus, Vulnerability Manager Plus,
   Remote Access Plus и Endpoint Central строка Secure Gateway Server присутствует в таблицах
   всех редакций. Формулировки профиля «(Enterprise)» рядом со шлюзом нужно снять у всех трёх
   продуктов.
3. **Резервный сервер — надстройка, а не состав редакции.** Там, где failover есть, он вынесен
   в отдельную таблицу с собственными полосами. Формулировку «Enterprise добавляет… резервный
   сервер консоли» нужно переписать у Patch Manager Plus.
4. **«По запросу» устарело в двух местах.** Бессрочная лицензия и дополнительные пользователи
   консоли на витрине заведены прайсовыми позициями у всех продуктов набора; формулировки
   «бессрочная — по запросу» и «стоимость дополнительных техников — по запросу» следует
   заменить на описание модели без чисел.
5. **DATA GAP по рабочим станциям закрыт у трёх продуктов** — Patch Manager Plus,
   Vulnerability Manager Plus, OS Deployer. Минимальные объёмы различаются: Patch Manager Plus —
   50 компьютеров, Vulnerability Manager Plus и OS Deployer — 100 рабочих станций,
   Endpoint Central — 50 конечных точек.
6. **Не покрыто снимками этого набора:** Endpoint DLP Plus, Endpoint Central MSP,
   Mobile Device Manager Plus MSP, а также любые бесплатные редакции. Все утверждения профиля
   и семейства по ним остаются на прежнем основании.
