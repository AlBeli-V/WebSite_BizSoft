  DataSecurity Plus, а не внутри DataSecurity Plus.
- Хлебные крошки страницы: `FileAnalysis Home » Security information and event management »
  FileAnalysis`.
- Собственный прайс-блок «FileAnalysis Professional Edition» с собственным рядом объёмов,
  собственный переключатель «Subscription / Perpetual» и собственная кнопка «Get Price Quote».
- Собственное описание назначения: `Control unstructured data growth and detect file security
  vulnerabilities using FileAnalysis.`
- DataSecurity Plus на странице встречается только как пункт бокового меню — ни как требование,
  ни как носитель лицензии.

продукта — верны. Опровержения нет.

- **Сходится:** единственная редакция Professional; единица — терабайт; стартовый пакет 2 ТБ;
  подписка и бессрочная лицензия; AMS «Included»; оговорка о крупных средах.

  - В снимке: `2 TB US$145`, `5 TB US$295`, `10 TB US$495`, `15 TB US$645`, `20 TB US$745`,

  - Правка: «Ряд витрины — 2 / 5 / 10 / 15 / 20 / 40 / 50 ТБ; по запросу — только крупные среды

- **Расхождение 3 — источник.**

  - Подтверждён адрес витрины: `https://store.manageengine.com/file-analysis/` — поставить в

## Log360 — раздела в профиле НЕТ

Снимок `cfecf0f2aa91` → https://store.manageengine.com/log-management/

- **Проверено:** заголовка `# Раздел · Log360` в профиле нет. Log360 встречается только

- **Что даёт снимок:**
  - Назначение: `an integrated solution that combines EventLog Analyzer and ADAudit Plus into
    a single console` — Log360 это зонтик над продуктами, которые у нас уже заведены.
  - Статичного прайс-ряда на странице нет: блок «ManageEngine Log360 - Subscription Model»
    показывает `Total US$0` — цена собирается конфигуратором, и снимок текста её не содержит.
  - Оси лицензии видны в разметке конфигуратора: число источников журналов (10 / 25 / 50 /
    100 / 250), контроллеров домена (2 / 5 / 10 / 15 / 20), файловых серверов Windows
    (2 / 5 / 10 / 15 / 20; подпись «Windows File Servers, NAS Storage devices»), рабочих
    станций («Windows Workstation & Mac») и облачных учётных записей (1 / 2 / 3 / 5).
  - Надстройка: резервное копирование и восстановление AD — `AD backup and recovery add-on is
    licensed based on the number of Domain controllers.`
  - Отдельные позиции внедрения: Advanced Onboarding and Implementation (Online и Onsite),
    обучение до 4 участников.
  - Вкладки «Perpetual» на странице нет — только подписка, плюс отдельная ссылка «Pricing for
    Cloud Edition» и «License guidelines».

- **Есть ли смысл заводить раздел: да, но не по одному этому снимку.**
  Довод за: Log360 объединяет четыре позиции, которые у нас уже есть (EventLog Analyzer,
  ADAudit Plus, Cloud Security Plus, DataSecurity Plus), и объясняет их единицы — ряд облачных
  учётных записей в Log360 буквально совпадает с рядом Cloud Security Plus, ряд файловых
  серверов — с рядом DataSecurity Plus. Без раздела мы не можем ответить на вопрос клиента
  «брать модули по отдельности или Log360 целиком».
  Довод против немедленного заведения: снимок даёт единицы, но не даёт ни цен, ни границ
  редакций, ни условий облачной поставки. Нужен отдельный сбор страниц «License guidelines»
  и «Pricing for Cloud Edition» плюс снятие конфигуратора с выбранными объёмами.
  Предложение: завести раздел после дополнительного сбора; в текущем профиле — не выдумывать.

## EventLog Analyzer — раздела в профиле НЕТ

Снимок `411f30fe0d65` → https://store.manageengine.com/eventlog/

- **Проверено:** заголовка `# Раздел · EventLog Analyzer` в профиле нет; продукт упоминается
  только в неопределённости 3 раздела Cloud Security Plus.

- **Что даёт снимок (данных заметно больше, чем по Log360):**
  - Единица названа прямо: `licensed based on the number of log sources (devices, applications,
    Windows servers, and workstations) added for monitoring`.
  - Правило счёта, которое почти наверняка спросят: `If you monitor an application and also the
    server in which the application is installed, then you will be licensed for 1 log source.`
  - Оси конфигуратора: число источников журналов (10 / 25 / 50 / 100 / 250), конечных точек
    (Endpoints), облачных учётных записей.
  - Редакции: в конфигураторе выбор «Premium» / «Distributed» со ссылкой «Compare Editions».
    Внимание: строки корзины при этом подписаны «EventLog Analyzer Professional Edition -
    Log Sources» — витрина сама себе противоречит в названиях; в тексты это разночтение
    выносить нельзя, только в неопределённости.
  - Модель срока: только подписка, вкладки «Perpetual» на странице нет (в отличие от
    SharePoint Manager Plus, M365 Security Plus, Cloud Security Plus и DataSecurity Plus).
    Цена — `Total US$0` до выбора в конфигураторе.
  - Услуги: Standard и Advanced Onboarding, обучение до 4 участников.

- **Есть ли смысл заводить раздел: да.**
  Единица и правило её счёта названы на самой странице — это уже достаточная основа для
  терминологии и подписи единицы («пакет: N источников журналов»). Не хватает двух вещей:
  состава редакций Premium / Distributed (нужна страница сравнения редакций) и ступеней цены
  (конфигуратор). Раздел можно писать сразу, оставив эти два пункта в «Неопределённостях»,
  либо добрать их тем же сбором, что и по Log360 — второе предпочтительнее, продукты смежные.
