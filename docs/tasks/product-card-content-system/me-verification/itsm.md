**Р-1. Полосы Standard: пропущена полоса 25 техников.**
- Профиль: «Standard: только техники — 10 / 20 / 50 / 100 / 200 (до 5 — бесплатно)».

- Цитата (`a34f339547ed.txt`, стр. 44–46): `25 Technicians` / `US$2,995` / `Included`.
- Правка: «Standard: только техники — 10 / 20 / 25 / 50 / 100 / 200 (до 5 — бесплатно)».

**Р-3. AMS: утверждение «только для бесплатной редакции» снимком не подтверждается.**

  пример строки — стр. 38–40: `10 Technicians` / `US$1,195` / `Included`.
- Правка: «В годовой подписке обслуживание и поддержка (AMS) включены в цену каждой полосы и
  каждой надстройки; отдельной строкой AMS оплачивается только к бессрочной лицензии».
