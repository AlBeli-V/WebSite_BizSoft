## 0. Резюме (TL;DR)

1. **Видимость сайта в поиске сейчас — нулевая или околонулевая.** По запросам `site:biz-soft.pro` и по бренду сайт не находится в Google-индексе (проверка через US-выдачу). Домен молодой в контентном смысле: первые статьи блога — июнь 2026, ссылочный профиль фактически отсутствует. Это не «плохое SEO» — это стадия «нас ещё нет на карте».
2. **Органическая выдача по всем деньгоносным кластерам ниши занята не сайтами конкурентов, а их статьями на трастовых платформах**: vc.ru, DTF, Habr (корпоративные блоги), Klerk.ru, Sostav, «РБК Компании». Прямые конкуренты (oplatym.ru, pay-saas.ru, oplata.guru, migsoft.ru, softmart.ru, ml-soft.ru, b2b-saas.ru) стоят в топе преимущественно «чужими руками» — через платформенный контент. Следовательно, **главный рычаг отбора трафика — параллельный контент-маркетинг на тех же площадках + добор НЧ/СЧ собственными посадочными**, а не лобовая борьба за ВЧ своим доменом.
3. **Техническая база сайта на удивление хорошая** (Astro, JSON-LD почти на всех типах страниц, FAQ-разметка, summaryAnswer под AI-сниппеты, самохост шрифтов, динамический OG для товаров). Но есть ~15 конкретных дефектов, из которых 5 — критичные (внутренние 301 из-за слешей, несклеенный www, `noindex,nofollow` на фильтрах, дубли BreadcrumbList/FAQPage, дыра в robots.txt для секций ботов). Все фиксы дешёвые — это задача на 1–2 дня разработки, финальный промт для Claude Code приложен в §13.
4. **GEO (видимость в AI-ответах) — правильная ставка для этой ниши** («как оплатить X из России» — типовой вопрос к ChatGPT/Perplexity), и половина фундамента уже есть. Нужно: обновить устаревший `llms.txt`, добить структурированные ответы, и главное — **внешние упоминания**, потому что AI-поисковики цитируют то, что уже цитируется в вебе.
5. **План действий на 6 месяцев:** месяц 1 — технические фиксы + аналитика; месяцы 1–3 — 12–16 внешних статей на 7 площадках (детальные ТЗ в §7) + масштабирование vendor-лендингов; месяцы 3–6 — отзывы, рейтинги, Яндекс-экосистема, наращивание compare/solutions, поддерживающий контент. Реалистичная цель: 3–5 тыс. органических визитов/мес к февралю 2027 и присутствие в AI-ответах по 10+ кластерам.

## 1. Методология и ограничения

**Что делалось:**
- Полная инвентаризация кодовой базы (Astro 5 + Directus, гибрид SSG/SSR) — метатеги, разметка, sitemap, robots, маршруты, контент, перелинковка, аналитика.
- Анализ поисковой выдачи Google по брендовому запросу, `site:` и 4 коммерческим кластерам («ChatGPT для юрлица», «JetBrains для юрлица», «Figma юрлицо», «оплата зарубежных сервисов для юрлиц»).
- Идентификация конкурентов и их каналов трафика по составу выдачи.
- Сверка с внутренними документами команды (`docs/homepage-benchmark-softline.md`, `docs/ai-catalog-redesign.md`) — чтобы не дублировать уже принятые решения, а достраивать их.

**Ограничения (важно для интерпретации):**
- Аудит проводился из среды с сетевыми ограничениями: живой сайт biz-soft.pro и сайты конкурентов напрямую недоступны, выдача Google проверялась через US-прокси, выдача Яндекса напрямую не проверялась. Поэтому фронт оценён по коду репозитория (он полностью определяет прод), а поисковая картина — по составу англо-агрегированной выдачи. **Первое действие команды — контрольные проверки из §2.3.**
- Данные Метрики/Search Console/Вебмастера не предоставлялись — базовые метрики трафика надо снять до старта работ, иначе не с чем будет сравнивать.

## 2. Текущая видимость в Google и Яндексе

### 2.1. Google

- `site:biz-soft.pro` — прямых результатов нет; выдача подменяется похожими доменами (soft-pro.com, soft-pro.biz). Вывод: **индексация отсутствует или единичная**, PageRank-сигналов нет.
- Брендовый запрос «biz-soft.pro» — сайт не находится. Брендовая выдача не сформирована: нет карточки организации, нет упоминаний на сторонних площадках.
- Ссылочный профиль: по косвенным признакам — около нуля. Ни одного упоминания на vc/habr/klerk/отзовиках не обнаружено.

### 2.2. Яндекс (оценка + гипотезы для проверки)

Для ниши «оплата зарубежного ПО юрлицом» Яндекс — **основной** поисковик (аудитория — российские ИТ-директора, бухгалтеры, закупщики). Яндекс быстрее Google индексирует новые русскоязычные сайты и лояльнее к молодым доменам в НЧ-выдаче, поэтому первые позиции появятся именно там. Но у Яндекса свои требования, по которым сейчас есть пробелы:

- **`Clean-param` в robots.txt отсутствует**, при этом каталог генерирует параметрические URL (`?vendor=`, `?license=`, `?ptype=`, `?q=` — `src/pages/catalog/[segment].astro:36-39`). Для Яндекса это прямой источник дублей.
- **Яндекс Бизнес / карточка организации** — по коду и выдаче признаков нет. Для B2B с московским адресом и телефоном это бесплатная брендовая выдача + пункт на Картах.
- Поведенческие факторы (главный фактор Яндекса) пока копить не на чем — сначала нужен трафик из контент-канала.

## 4. GEO: видимость в AI-поисковиках (ChatGPT Search, Perplexity, Яндекс Нейро, Алиса)

Ниша идеальна для GEO: вопрос «как оплатить ChatGPT/JetBrains/Figma из России юрлицу» — типовой запрос к AI-ассистентам, и AI-ответ с упоминанием BIZSoft = лид с нулевой ценой клика. Половина фундамента уже построена (это редкость): `summaryAnswer` в статьях и сравнениях, FAQ-разметка на 16 типах страниц, `llms.txt`, разрешённые AI-краулеры (GPTBot, ClaudeBot, PerplexityBot, OAI-SearchBot, Claude-SearchBot, Amazonbot, Meta-ExternalAgent).

**Что доделать:**

1. **Переписать `llms.txt`** (П-8): актуальная структура каталога (`/catalog/ai` + 8 подкатегорий, `/vendors` с полным списком, `/compare`, `/solutions`), все 7 статей, УТП одним абзацем с фактами (договор, счёт в ₽, ЭДО, ИНН, с 2022 года). Добавить `llms-full.txt` с развёрнутым описанием топ-20 страниц.
2. **Единый «блок прямого ответа»** вверху каждой коммерческой посадочной: 2–3 предложения, отвечающие на вопрос «как купить X юрлицу из РФ» с конкретикой (срок, документы, валюта счёта). AI-модели цитируют первые самодостаточные абзацы. На vendor-лендингах это уже частично есть — стандартизировать как обязательный блок шаблона.
3. **Таблицы с фактами** (тарифы, сроки, документы) — LLM предпочитают извлекать данные из таблиц; в `vendor-content.ts` таблицы уже есть, добить на bespoke-лендинги.
4. **Внешние упоминания — главный фактор GEO.** Perplexity и ChatGPT Search цитируют домены, которые уже цитируются: vc.ru, habr, klerk в этой нише — постоянные источники AI-ответов (проверено на выдаче: те же статьи, что в топе Google, попадают в AI-цитаты). Каждая внешняя статья из §7 — одновременно и SEO-, и GEO-актив. В статьях всегда упоминать бренд «BIZSoft (biz-soft.pro)» текстом, а не только ссылкой.
5. **Мониторинг:** раз в 2 недели прогонять 15 контрольных промтов («как оплатить figma юрлицу из россии», «chatgpt team для компании рф как купить» и т.д.) через ChatGPT, Perplexity, Нейро; вести таблицу «упомянуты/нет, кто упомянут». Это KPI GEO-канала (§11).

## 5. Конкурентный ландшафт и стратегия отбора трафика

### 5.1. Карта конкурентов

**Тип А. Платёжные посредники-агрегаторы** (B2C с B2B-надстройкой): oplatym.ru, pay-saas.ru («Плати Легко»), getpayall.com, oplata.guru, wanttopay.net, ruscribe.ru, virtualcards.shopping.
Сильны: массовые лендинги «оплатить {сервис} из России» под сотни сервисов, агрессивный платформенный контент. Слабы: B2C-позиционирование, слабые документы для бухгалтерии, нет отраслевой экспертизы.

**Тип Б. B2B-реселлеры ПО — прямые конкуренты**: softmart.ru, migsoft.ru, ml-soft.ru, b2b-saas.ru.
Сильны: та же модель (договор, счёт, ЭДО), уже в индексе, есть карточки продуктов. Слабы: узкие каталоги (часто 1–2 вендора), шаблонные тексты, почти нет сравнений и отраслевых страниц — ровно то, что у BIZSoft уже построено лучше.

**Тип В. Контент-платформы, занимающие топ выдачи**: vc.ru, dtf.ru, habr.com (корпблог «Ранвик» и др.), klerk.ru (блог easycrds), sostav.ru, companies.rbc.ru.
Это не конкуренты, а **поле боя**: 70–90% топ-10 по коммерческим запросам ниши — статьи на этих доменах. Кто размещает больше и лучше статей — тот собирает трафик.

**Тип Г. Классические дистрибьюторы** (Softline/store.softline.ru, Syssoft): сильны по «традиционному» софту и бренду, слабы в кластере «зарубежные подписки под санкциями» — они его почти не отрабатывают. Команда уже использует Softline как бенчмарк UX (`docs/homepage-benchmark-softline.md`) — правильно; в SEO с ними в лоб не бодаться, обходить в санкционно-подписочном кластере.

### 5.2. Из чего состоит выдача (важнейший вывод аудита)

По всем четырём проверенным кластерам картина одинакова:

- Топ занят **обзорно-инструктивными статьями на UGC/медиа-платформах** («Как оплатить X из России в 2026: N способов») — по 3–6 позиций из топ-10.
- Далее — **лендинги посредников** типа А под точные запросы «оплатить X».
- Собственные сайты B2B-реселлеров — в хвосте топ-10 и по НЧ («купить X для юрлица по счёту»).
- Заголовки конкурентов всегда содержат **год** («в 2026 году») и регулярно переобновляются — статьи-«вечнозелёнки» с ежегодным рефрешем.

### 5.3. Стратегия отбора доли трафика (4 направления)

**Направление 1 — «встать на их площадки» (парасайт-SEO).** Размещать свои статьи на тех же трастовых доменах, которые уже ранжируются: vc.ru, DTF, Habr, Klerk, Sostav, «РБК Компании», Spark.ru, TenChat, Дзен. Молодой домен не обгонит vc.ru, но статья BIZSoft на vc.ru обгонит статью конкурента на vc.ru, если она полнее и свежее. Детальный план — §7.

**Направление 2 — «B2B-клин».** Конкуренты типа А держат B2C-формулировки («оплатить подписку»). BIZSoft бьёт в чисто корпоративную семантику, где конкуренция ниже, а чек выше: «{вендор} для юрлица», «по счёту», «закрывающие документы», «с НДС», «через ЭДО», «на компанию», «корпоративный тариф», «enterprise». Эта семантика уже зашита в шаблоны vendor-лендингов — масштабировать эксперимент `seo-experiments.ts` (сейчас 5 страниц) на все 50+ вендоров волнами по 10–15 с контролем CTR через GSC/Вебмастер.

**Направление 3 — «перехват сравнением».** У конкурентов почти нет сравнений — у BIZSoft уже 14 страниц `/compare/*`. Расширить до 30+ (список в §8.2): сравнительные запросы («cursor vs copilot для команды») — это горячие B2B-пользователи на стадии выбора, и эти же страницы активнее всего цитируются AI-поисковиками.

**Направление 4 — «фактор доверия, которого нет у посредников».** Реальные реквизиты (ИНН/ОГРНИП в футере и в schema уже есть), кейсы, отзывы клиентов-юрлиц с названием компании, рейтинг на отзовиках. Цель — за 6 месяцев собрать 15–20 отзывов (Яндекс Бизнес, Отзовик, 2ГИС) и вывести честный `aggregateRating` в Product-разметку (в бенчмарк-доке это уже помечено как P2 с правильной оговоркой «не выдумываем»).
