# Регулярное правило: поля форм с ПДн — класс ym-disable-keys

Установлено руководителем 03.09.2026 (вебвизор Метрики остаётся включённым).
Любое поле ввода персональных данных на публичной странице (ФИО, e-mail,
телефон, компания, ИНН, текст обращения) несёт класс `ym-disable-keys`:
Вебвизор не записывает ввод в нём независимо от настроек кабинета. Проверка
автоматическая — `tests/webvisor-masking.test.ts` роняет `pnpm test`. Что
настроено в кабинете и как смотреть записи — `docs/marketing/webvisor.md`.
