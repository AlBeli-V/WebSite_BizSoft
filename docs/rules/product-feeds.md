# Товарные фиды: открытие только по команде руководителя

Установлено руководителем 29.08.2026. Действует во всех ветках и сессиях.

Товарные фиды (`/yandex-products.yml`, `/yandex-business.xml`,
`/yandex-direct.yml`, `/yandex-market.yml`, любые будущие) держатся
готовыми, но ЗАКРЫТЫМИ: по умолчанию отдают 404 (`X-Feed-Status: disabled`).
Решения о публикации принимает только руководитель. Без его явной команды
нельзя: включать `YANDEX_FEEDS_ENABLED` на проде, добавлять фиды в кабинеты
Яндекса, отправлять обращения в поддержку площадок, загружать YML куда-либо.
Подробности — `docs/yandex-feeds.md`.
