# Регулярное правило: новые вендоры/товары → микроразметка

Установлено руководителем 29.08.2026. При добавлении вендоров и товаров
микроразметка Schema.org обязательна и делается ТОЛЬКО штатным слоем
(`src/lib/seo.ts`, компоненты `Breadcrumbs`/`FAQ`/`JsonLd`, microdata
карточки товара) — руками в шаблонах ничего не размечать. Один тип — один
раз на страницу (BreadcrumbList — только компонент Breadcrumbs, FAQPage —
только компонент FAQ). «Цена по запросу» — без Product/Offer вовсе;
фиктивные цены/рейтинги запрещены. Цена в разметке — из `effectivePrice()`.
Приёмка: `pnpm verify` (смоук сверяет JSON-LD ↔ microdata ↔ видимую цену).
Подробности: `docs/seo/structured-data-audit.md`,
`docs/vendors-expansion-prompt.md` (раздел 11).
