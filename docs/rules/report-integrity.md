# Достоверность отчётов: данные, не литералы

Установлено 03.09.2026 по аудиту `docs/ops/report-integrity-audit-2026-09-03.md`
(письмо GI две недели печатало зашитую фразу «ждёт токена Вебмастера»).
Действует во всех ветках.

- **Литералы без срока годности запрещены** в тексте отчётов, промптов и
  записей журнала: даты, обещания («появится после», «следующий шаг»,
  «подготовлю», «ждёт»), «ещё не собран», суммы, квоты. Проверка —
  `scripts/seo/tests/test_report_literals.py`; исключения только в
  `data/reports/literal-allowlist.json` с причиной и `valid_until`.
- **Недоступный блок письма — только через `scripts/seo/passport.py`**:
  код причины из перечня, текст из словаря, дата данных `as_of` и пометка
  `stale` при отставании. Правило одной строкой: код не различает причину —
  текст её не называет.
- **Инварианты двух уровней** (`scripts/seo/invariants.py`): ложь о дате или
  причине блокирует выпуск письма (`<дата>-v4-blocked.json`, код 2,
  уведомление о сбое с причинами), форма — мягкое нарушение в JSON.
- **Журнал со статусом**: запись в issue #22 из workflow — только через
  `.github/actions/journal-post` с `outcome` основного шага (✓/✗, красный
  прогон при неуспехе). `|| true` и `exit 0` после «не найден» вокруг
  основного скрипта запрещены: вывод в output, шаг завершается кодом
  скрипта. Храповик — `tests/workflows-lint.test.ts`, база
  `data/reports/workflow-lint-baseline.json` только убывает.
- **Реестр секретов** `ops/secrets/registry.json`: каждое `secrets.X`
  зарегистрировано с назначением (`tests/secrets-registry.test.ts`); второе
  имя одного токена — долг с `resolve_by`.
- **Срок годности одноразовых workflow**: `# expires:` в шапке, просроченный —
  в `.github/workflows-archive/` или продление через PR.
- **Сравнение только по полным окнам**: недельные и периодные агрегаты не
  сравниваются, пока оба окна не покрыты данными целиком; источник без
  данных печатается «—», а не «0».
