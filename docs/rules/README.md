# Правила проекта: полные тексты

`CLAUDE.md` в корне — короткий свод, который читается в каждой сессии. Здесь —
полный текст каждого правила с датой установления, обоснованием и разбором
инцидентов. Новое правило заводится так: строка-две в `CLAUDE.md` со ссылкой
на файл здесь, полный текст — в файл.

## Как работать
- `approach-check.md` — проверка подхода до начала работы
- `language.md` — язык: результат по-русски, внутренние рассуждения любые
- `decisions-buttons.md` — запросы решений кнопками с визой
- `timezone.md` — время по Москве
- `mail-recipient.md` — адрес получателя писем

## Прод и операции
- `prod-access.md` — доступ к прод-серверу
- `production-workflow-main-only.md` — production-workflow только с main
- `operational-runs.md` — операционные прогоны только в GitHub Actions
- `operational-routines-history.md` — история прежнего механизма Routine (заменён)
- `product-feeds.md` — товарные фиды открываются только по команде руководителя
- `data-sources-registry.md` — источники и аккаунты в реестрах с переключателем

## Каталог, страницы, SEO
- `catalog.md` — каталог и привязки
- `sitemap-indexing.md` — новые страницы → sitemap → индексация
- `structured-data.md` — микроразметка
- `webmcp.md` — WebMCP
- `webvisor-masking.md` — поля форм с ПДн: класс ym-disable-keys
- `unique-meta.md` — уникальные title и description
- `snippet-experiments.md` — сниппет-эксперименты только на страницах с показами
- `serp-single-source.md` — SERP: один сбор, все потребители
- `vendor-decisions-registry.md` — решение по кандидату в машинный реестр
- `spec-line.md` — спецификация `/cart`: состав таблицы и описание позиции как предмет договора
- `email-rent.md` — аренда адресов электронной почты: выбор в шапке спецификации
- `quote-document.md` — документ КП: таблица как спецификация, листы, шрифт
