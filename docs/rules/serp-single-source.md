# SERP: один сбор — все потребители

Установлено 03.09.2026 с подключением xmlriver (российская выдача Google).
Действует во всех ветках и сессиях. Подробности —
`docs/competitive/decisions-2026-09-03.md`.

- Выдачу собирает только workflow `seo-serp-watch` (Яндекс — Search API,
  ежедневно; Google RU — xmlriver, еженедельно) в `reports/seo/serp`
  ветки `seo-data`. Потребители — веб-отчёт Growth Intelligence
  (`scripts/seo/serp_analysis.py`) и конкурентная разведка
  (`competitive-intelligence/discovery/serp_source.py`) — читают готовый
  срез. Прямые вызовы xmlriver/DataForSEO из контуров-потребителей и любые
  параллельные сборщики SERP запрещены.
- Google RU — серия `google_ru` (местоположение 2643, глубина 20 позиций:
  две страницы по 10, страницы xmlriver нумеруются с единицы). Прокси-гео через
  DataForSEO снято; автоматического запасного источника нет: без свежего
  среза (8 дней) показывается «нет данных», а не старые позиции и не ноль.
  Позиции Яндекса и Google как равноточные не сравниваются — сравнивается
  присутствие в топе.
- Повторный запуск сборщика за ту же дату докачивает только недостающее
  (`--refetch` — полный пересбор). Расход — по журналам
  `ledger/google-<месяц>.jsonl` (вызовы) и `ledger/google-runs.jsonl`
  (прогоны). Потолки и расписание меняются только через PR в
  `data/seo/xmlriver.json`.

## Одна потребность — один запрос в ядре

Вебмастер отдаёт часть запросов в переставленном виде: «оплата capture one
юридическим лицом» и «capture оплата one лицом юридическим» — одна запись
кабинета в двух формах. По буквальному совпадению это два разных запроса,
и ядро SERP-watch собирало выдачу по обоим. Ключ схлопывания в
`serp_watchlist.build` — смысловой (`wordstat/normalize.morph_key`:
стемминг, отбрасывание стоп-слов, сортировка), остаётся первая форма — та,
по которой показов больше.

Разбор 09.09.2026: срез нёс 431 запрос, из них 33 в 29 группах — вторые формы
того же смысла. Это 8% дневного бюджета выдачи, а счёт «мы в топ-10 по 230
запросам» и таблица разрыва Яндекс ↔ Google выходили завышенными: пять строк
из пятнадцати верхних были двойниками, и по переставленной форме сайт стоял
первым просто потому, что её никто не набирает.
