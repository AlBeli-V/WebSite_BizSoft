# Регулярное правило: сниппет-эксперименты — только на страницах с показами

Установлено руководителем 03.09.2026 перезапуском SEO-EXP-002 (разбор —
`docs/seo/experiments/seo-exp-002-restart.md`). Действует во всех ветках и
сессиях.

- Сниппет-эксперимент (title/description/FAQ) ставится только на страницах,
  у которых уже есть показы в Вебмастере (GAP-D). Частотность Вордстата —
  приоритет, а не отбор: по «adobe купить» сайта в выдаче нет, и сниппет
  этого не изменит. Целевые фразы — из фактических запросов Вебмастера.
- В реестре (`reports/seo/intelligence/seo-experiments.json`, ветка
  seo-data) у сниппет-эксперимента обязательны `page_markers` (маркеры
  запросов каждой страницы), `query_intent_any`, `query_exclude`,
  `title_marker` и `baseline` с показами по каждой странице; принадлежность
  запросов странице сверяется по SERP-срезу. Статус при заведении —
  `planned`, `start: null`: в `running` его переводит `seo-site-check` по
  факту выката (`scripts/seo/experiment_windows.py activate`), он же
  записывает фиксированные окна; выгружает их `seo-data-collect`.
  Руками `start` и окна не проставлять.
- **Порог экспозиции при заведении** (решение 04.09.2026). Любой новый
  эксперимент — сниппетный или контентный — заводится только на кластере с
  экспозицией выше 3,6 показа в день (100 за 28 дней). Порог нормирован на
  длину окна источника: скользящая выгрузка Вебмастера покрывает ~12 дней,
  фиксированное окно — 28, и абсолютное число сравнивало бы несравнимое.
  Проверка машинная — `python3 scripts/seo/experiment_windows.py validate`
  перед отправкой реестра в seo-data; возврат 1 при нарушении. Правило ловит
  и затухший всплеск: у кластера Recraft 180 показов за август (внешняя
  публикация на klerk.ru) и 0,3 показа в день к сентябрю. Идущие
  эксперименты правило не пересматривает.
- Экспериментам, заведённым до появления фиксированных окон, baseline
  проставляется задним числом (`experiment_windows.py backfill`): окно до
  старта целиком в прошлом, и Вебмастер отдаёт его полным обходом. Окно
  «после» у них остаётся скользящим, сравнение помечается предварительным.
- Один эксперимент — одно изменение; блоки контента (ссылки на решения,
  статьи) — отдельным экспериментом со своей датой.
- После деплоя — переобход страниц через `ops-yandex-recrawl`.
- **Кластер под замером в радар возможностей не попадает.** Пока эксперимент
  идёт, его страницы под мораторием: рекомендованная правка заголовка и
  описания обнуляет замер. Радар сверяет кластер с `query_markers`
  действующих экспериментов и вместо правки называет тикет; такие кластеры
  перечисляются отдельной строкой «придержаны до вердикта», чтобы их
  отсутствие в тройке не читалось как отсутствие спроса. Разбор 09.09.2026:
  из трёх позиций радара две мерялись опытом (CONTENT-003 и SEO-EXP-004), а
  в таблице money-запросов таких строк было шесть из девяти верхних.
