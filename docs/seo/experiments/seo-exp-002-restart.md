# SEO-EXP-002: разбор и перезапуск (03.09.2026)

Команда руководителя 03.09.2026: «делай перезапуск эксперимента, текущая
конфигурация не работает и не показала эффект как от внедрения, так и самой
методики исследования, осмысли и измени подход». Это решение отменяет
решение KEEP того же дня (журнал `experiment-decisions.jsonl`, запись
NEW_TEST от 03.09.2026).

## Что было

`snippets-6-demand` (SEO-EXP-002), старт 20.08.2026: шесть vendor-страниц
(Adobe, Autodesk, Procreate, Blackmagic/DaVinci, Midjourney, Clip Studio
Paint), отобранных по частотности Вордстата («adobe купить» — 3 887/мес,
«autodesk license» — 1 800, «купить procreate» — 823, «davinci resolve
купить» — 531, «clip studio paint купить» — 417, «midjourney подписка» —
380). Одной правкой: коммерческий title, description «Оплатим подписку…»,
FAQ «Как купить {Vendor} на юрлицо», блок ссылок на /solutions. Цель —
«фразы кластера в топ-10 и CTR ≥2% за 14 дней».

Итог на 14-й день: 100 показов кластера, 1 клик, вердикт движка
«мало данных», совпадающих запросов между окнами — 2.

## Почему не сработало

Разобрано по выгрузкам Вебмастера `reports/seo/data/yandex-*.json`
(18.08–03.09), SERP-срезам `reports/seo/serp/*.jsonl` и решениям в
`experiment-decisions.jsonl`. Пять дефектов, три из них — методические.

1. **Атрибуция приписывала странице чужие показы.** Маркеры кластера Adobe
   («after effects», «lightroom», «premiere pro») ловили запросы «купить
   after effects юридическим лицом» (31 показ, позиция 4) и «купить
   lightroom юридическим лицом» (13, позиция 3,5). SERP-срез 03.09 показывает
   по ним карточки `/product/adobe-ae` и `/product/adobe-lr`, а не
   `/vendors/adobe`. Это 44 из 100 показов «кластера». Ещё два «показа»
   Blackmagic — навигационные «blackmagic com». Единственный клик —
   по навигационному запросу «adobe купить для компании biz-soft.pro».
2. **У пяти из шести страниц экспозиции нет.** По всем выгрузкам за
   17 дней: Autodesk — 1 показ («подписка на autocad для юр лиц», позиция
   12), Midjourney — 1–3, Blackmagic — 0 покупательских, Adobe (сама
   vendor-страница) — единицы. Живая экспозиция только у Clip Studio Paint
   (55 запросов, 60–86 показов за окно, позиции 6–12, кликов 0) и Procreate
   (12 запросов, ~20 показов, позиции 5–14, кликов 0). Сниппет влияет на
   долю кликов при показе; без показов проверять нечего — CTR-тест на такой
   группе не мог дать вывод ни при какой длительности.
3. **Целевые фразы Вордстата — не наш интент.** По всем шести фразам
   («adobe купить», «купить procreate», «davinci resolve купить» и т. д.)
   в топ-10 Яндекса — Маркет, Ozon, Wildberries, ggsel, сайт не показывается
   вовсе (SERP-срез 03.09: наших URL нет). Сниппет не меняет показов и
   позиций; целевой показатель «появление фраз в топ-10» для
   сниппет-эксперимента невыполним по построению. Частотность Вордстата
   годится для приоритизации, но не для выбора страниц сниппет-теста.
4. **Baseline из усечённой выгрузки.** До 23.08 сборщик брал только
   топ-100 запросов из ~450; постраничный обход появился позже. «23 показа →
   100» и «CTR 0% → 1%» — артефакт смены глубины выгрузки, а не эффект.
   Окно источника скользящее (~12 дней), baseline в прошлом и не растёт —
   отсюда «совпадающих запросов 2» навсегда.
5. **Четыре изменения одной правкой** (title, description, FAQ, блок
   /solutions) на шести разнородных вендорах: вклад неразделим, а средние
   по «кластеру» скрывали страницы без показов.

Вывод о методике: сниппет-эксперимент ставится только там, где у страницы
уже есть показы (случай GAP-D), атрибуция запросов проверяется по SERP-срезу
(наш URL по запросу), а окна сравнения — равной длины и из полной выгрузки.

## Новый дизайн: `snippets-2-price-intent` (SEO-EXP-002-R)

**Страницы.** `/vendors/clip-studio-paint` и `/vendors/procreate` — две с
реальной экспозицией. Adobe, Autodesk, Blackmagic, Midjourney выведены из
сниппет-эксперимента; их сниппеты остаются как есть (KEEP 03.09.2026),
страницы освобождаются для кандидатов контентного приёма. Кластер Adobe
несёт отдельную находку: карточки `/product/adobe-ae` и `/product/adobe-lr`
стоят на позициях 1–4 по запросам «купить … юридическим лицом» с 44 показами
и нулём кликов — это GAP-D для отдельного эксперимента на карточках товаров.

**Приём.** Запросная формула под ценовой интент фактических запросов
Вебмастера (та же механика, что в SEO-EXP-004): фраза «сколько стоит
{Vendor} в рублях» / «купить в России» идёт первой в description и в первом
вопросе FAQ (`faqAdd`, собственный FAQ страницы сохраняется), в title —
«цена» и модель лицензии. Одно изменение — сниппет; блок /solutions и
контент страниц не трогаются. Формула входит в группу
`query-phrase-snippet-2026-09` вместе с SEO-EXP-004 — пул даёт мощность,
которой у двух малых кластеров по отдельности нет.

| Страница | Реальные запросы (показы за окно, позиция) | Новый title |
|---|---|---|
| Clip Studio Paint | «купить подписку на клип студио пейнт» (7, 11,6), «клип студио купить лицензию навсегда» (5, 8,3), «сколько стоит подписка в клип студио» (4, 10), «сколько стоит клип студио в рублях» (3, 8,4), «бессрочная лицензия клип студио» (3, 6,3) | Clip Studio Paint: цена бессрочной лицензии и подписки в рублях |
| Procreate | «procreate цена» (5, 10,2), «прокриэйт цена» (4, 13,8), «procreate купить в россии» (3, 5), «сколько стоит procreate» (1, 12) | Procreate: цена в рублях и покупка в России на компанию |

**Измеритель.**

- Атрибуция по страницам: поле реестра `page_markers` (страница → маркеры
  её запросов), общий интент-фильтр `query_intent_any` (купить, цена,
  сколько стоит, подписка, лицензия, оплата, рубли, Россия, юрлицо) и
  исключения `query_exclude` (скачать, торрент, взлом, бесплатно, кисти,
  уроки). Оценка и письмо показывают каждую страницу отдельно
  (`per_page`), вердикт — один на эксперимент.
- Фиксированные окна равной длины. Дата старта — факт выката: workflow
  `seo-site-check` (ежедневно 05:37 МСК) переводит `planned` → `running`,
  когда обе страницы отдают новый вариант (`title_marker`), и записывает
  окна: baseline — 28 дней, заканчивающихся за 3 дня до старта (лаг
  источника); experiment — 28 дней со следующего дня после старта.
  `seo-data-collect` выгружает каждое окно полным обходом
  (`scripts/seo/experiment_windows.py fetch`) в
  `reports/seo/data/yandex-window-<from>_<to>.json`, как только его
  последний день устоялся. Вердикт-движок берёт эти файлы прежде скользящих
  выгрузок.
- Метрика: CTR по совпадающим запросам страницы за 28 дней при средней
  позиции не хуже базовой ±1; вспомогательно — пул формулы. Ёмкость Clip
  Studio ~150 показов за 28 дней, Procreate ~45: у Procreate порог экспозиции
  не наберётся — на контрольной точке по нему публикуется описательный
  вывод, а не «эффекта нет».
- Контрольные точки — 7/14/28 дней от фактического старта, финальная — после
  выгрузки полного окна (старт + 31 день).

**Гарантии измеримости, которых не было в первой версии.** Показы у обеих
страниц есть сейчас (не прогноз по Вордстату); каждая страница подтверждена
в SERP-срезе по своим запросам (`/vendors/clip-studio-paint` — позиция 6 по
«сколько стоит подписка клип студио бессрочная», 03.09); baseline
выгружается полным обходом за то же число дней, что и окно после; статус
`running` ставится по факту выката.

## Правила на будущее

Вынесены в `docs/seo/reporting-methodology.md` («Правила экспериментов»)
и CLAUDE.md:

1. Сниппет-эксперимент — только на страницах с показами (GAP-D). Спрос
   Вордстата задаёт приоритет, но не список страниц.
2. Атрибуция запросов — по страницам (`page_markers`) и с подтверждением
   SERP-срезом; целевые фразы — из показов Вебмастера, а не из частотности.
3. Baseline и окно после внедрения — фиксированные, равной длины, из полной
   выгрузки; дата старта — факт выката (activate), а не дата коммита.
4. Один эксперимент — одно изменение: сниппет отдельно от блоков контента.
