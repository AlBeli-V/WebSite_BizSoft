# Переход на отчётность v2

## Что изменилось

| Было (v1) | Стало (v2) |
|---|---|
| Текст письма писался вручную | Генерация из канонического snapshot: `snapshot.py → quality.py → charts.py → report_v2.py` |
| Один длинный отчёт | Executive brief (≤900 слов) + аналитическое приложение |
| Growth Score 0–100 | Четыре независимых статуса; score не рассчитывается (см. методику) |
| «Топ-10» при позиции ≤ 10,5 | Строгая граница ≤ 10 |
| Смешение запросов и страниц | Явное разделение scope |
| Ожидаемый CTR 3,3% и «потерянные клики» | «Ожидаемый CTR: нет утверждённой модели» |
| Цели Метрики назывались заявками | «Целевые события», лиды — «нет данных» до CRM |
| Показы назывались спросом | «Страницы получили N показов по запросам кластера» |
| Промты Claude в теле письма | Execution tickets в `reports/seo/tasks/` |
| Дельты от промежуточных сборов | Канонические значения + журнал ревизий |

## Удалённые и переименованные показатели

- `Growth Score` — удалён из письма, история сохранена в `score-history.json`.
- «Топ-10 выдачи» → «10 запросов с наибольшим числом показов» и «Запросы со средней позицией до 10».
- «Заявки-действия» → «целевые события».
- «Потерянные клики» — удалено (нет утверждённой CTR-модели).

| CTR 0,65% как узкое место | Помечено scope выборки; при critical `SOURCE_RECONCILIATION` вывод приостановлен |

## Как перейти

1. Ежедневный прогон: сбор → `snapshot.py` → `quality.py` → `report_v2.py`.
2. Письмо отправляет `reports/seo/intelligence/<дата>-executive.html`, plain-text — одноимённый `.md`.
3. Технические задачи ведутся тикетами `reports/seo/tasks/`, не промтами в письме.
4. Старые отчёты `reports/seo/<дата>.{md,html}` сохраняются как история и больше не генерируются.
