## 1. Принцип: не «ссылки → надежда», а «публикации → измерение → дожим»

Последовательность утверждена такой:

```
бесплатные публикации → измерение (индексация, показы, ссылки, позиции)
   → выявление кластеров-победителей → платные размещения только победителям
   → повторное измерение
```

Miralinks — не генератор ссылок, а усилитель уже доказавшего спрос кластера.
Воронка отбора: ~100 коммерческих кластеров → 30 получают внешний бесплатный
контент → 10 показывают потенциал → 5 получают платные размещения → 2–3
масштабируемых паттерна.

Три слоя программы:

| Слой | Что | Срок | Деньги |
|---|---|---|---|
| 1 | Собственные публикации: VC.ru, Дзен, Spark, TenChat | недели 1–8 | 0 ₽ |
| 2 | Редакционные упоминания: Pressfeed → отраслевые СМИ, подборки, рейтинги | с недели 3 | 0 ₽ / тариф Pressfeed |
| 3 | Платные размещения (Miralinks) — только по подтверждённым кластерам | не ранее недели 9 | по решению руководителя |

Приоритет площадок (сверху вниз): VC.ru → Дзен → Spark.ru → TenChat →
Pressfeed → Workspace. Пикабу в слое 1 **не используется**: продвижение
услуг ссылками там относится к коммерческой деятельности с отдельными
рекламными правилами — плохое соотношение риск/результат. DTF — только под
узкие темы (Autodesk, VFX, game-dev, Adobe).

**Habr из программы исключён** (решение руководителя 01.09.2026): площадка
платная, слой 1 строится только на бесплатных источниках. К вопросу
возвращаемся не раньше слоя 3 и только как к платному каналу наравне
с Miralinks.

## 3. Правила выбора целевых страниц и ссылок

Эти правила действуют для всех публикаций слоёв 1–3.

1. **Целевой URL берётся только из `/sitemap.xml`.** Если страницы нет в
   карте — она либо noindex, либо не готова; ссылку на неё не ставим.
2. **Не ссылаемся на шаблонные вендорские лендинги и тарифные карточки-
   близнецы**, пока их описания не уникализированы: это страницы,
   исторически снимавшиеся как МПК. Исключение — bespoke-лендинги (п. 2).
3. **Приоритет целей**: `/solutions/*` → `/compare/*` → bespoke `/vendors/*`
   → `/blog/*` → `/catalog/ai`. Главная — только как брендовая ссылка в
   профиле.
4. **2–3 ссылки на публикацию, не больше**: одна коммерческая (посадочная),
   одна–две информационные (блог/сравнение). Сплошная простыня ссылок
   читается площадкой и поисковиком как размещение.
5. **Анкоры**: на публикацию не более одного точного коммерческого анкора.
   Ориентир по всему массиву слоя 1: ~40% безанкорных/URL, ~30% брендовых
   («BIZSoft»), ~20% общих («поставщик зарубежного ПО»), ~10% точных.
6. **UTM**: SEO-ссылка ставится **чистой**, без меток. Метки допустимы во
   второй ссылке и в ссылке профиля — там, где площадка всё равно отдаёт
   nofollow/редирект. Схема меток: `utm_source=<площадка>&utm_medium=article&utm_campaign=ext-w1&utm_content=<slug-темы>`.
7. **Ни одна публикация не дублирует текст сайта.** Схема:
   исходная экспертная страница BIZSoft → адаптации под площадки. Копия
   статьи блога один в один — потеря и для площадки, и для сайта.

## 4. Объём первой недели: 8 публикаций из 3 контентных объектов

Рекомендация — **8 публикаций, 3 исходных контентных объекта, 4 профиля**.

| # | Действие | Кол-во |
|---|---|---|
| 1 | Регистрация профилей от лица BIZSoft: VC, Дзен, Spark, TenChat | 4 |
| 2 | Публикации: VC 1, Дзен 3, Spark 2, TenChat 2 | 8 |
| 3 | Заявки на Pressfeed (регистрация + ответы на 2–3 запроса) | 2–3 |

Тексты всех восьми публикаций написаны и лежат в
`docs/marketing/external/week1/` (+ Word-версия для внешнего ревью,
`exports/marketing/`).

Почему именно так:

- **Меньше четырёх площадок нельзя**: цель недели 1 — не ссылки, а замер,
  какие площадки дают индексацию и показы. С двух площадок вывод не строится.
- **Больше 8 публикаций вредно**: адаптации начнут повторять друг друга,
  а свежий аккаунт с потоком одинаковых коммерческих текстов ловит
  ограничения площадки. Дзен — единственный, где частота нужна (3 материала).
- **Все четыре площадки бесплатны** и допускают самостоятельную публикацию —
  это условие слоя 1.
- 3 объекта × 2–4 адаптации — это ровно тот объём, который один автор
  (в связке с Claude Code) проходит за неделю без падения качества.

Целевой результат недели 1 (проверяется на 7-й и 14-й день):
≥6 из 8 публикаций в индексе Яндекса, ≥3 внешние ссылки, обнаруженные
Вебмастером, ≥20 переходов суммарно, ≥1 публикация с показами по
небрендовым запросам.

## 7. Критерий перехода к платным ссылкам (слой 3)

Кластер получает платное размещение, только если одновременно:

1. позиция целевой страницы в Яндексе — 8–25 (есть что дожимать);
2. кластер имеет коммерческий спрос ≥ 1 000 показов/мес по ядру;
3. по кластеру уже есть ≥ 2 бесплатные внешние публикации, попавшие в индекс;
4. страница-цель не в списке МПК и не тарифная карточка-близнец;
5. за 4 недели после публикаций видна ненулевая динамика (позиции, показы
   или переходы) — то есть кластер отзывчив.

Пункты 1–5 проверяются автоматически из уже существующих данных
(`seo-serp-watch`, Вебмастер, Вордстат). Решение о деньгах — за руководителем.

## 8. Что программа требует от сайта

Внешний трафик придёт на страницы, которые Яндекс уже однажды снимал как МПК.
До массового наращивания ссылок:

- уникализировать описания карточек и лендингов по вендорам объектов A/B/C
  (через `data/seo/product-descriptions.json` + `ops-apply-descriptions`);
- после правок — переобход через `ops-yandex-recrawl`;
- проверить, что все целевые URL из раздела 5 присутствуют в `/sitemap.xml`
  и отдают 200 (`ops-index-validate`).
