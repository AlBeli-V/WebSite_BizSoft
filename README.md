# seo-data — хранилище данных конвейера Growth Intelligence

Orphan-ветка без общего предка с `main`: слить её в main нельзя даже случайно
(git откажет — unrelated histories), и она не увеличивает клон main.

Здесь живут только машинные данные; весь исполняемый код, workflow, шаблоны
и документация — в `main`:

| Каталог | Что это | Кто пишет |
|---|---|---|
| `reports/seo/data/` | сырые выгрузки GSC / Вебмастер / Метрика / GA4 по дням | workflow `seo-data-collect` |
| `reports/seo/wordstat/` | база семантики, журнал бюджета, состояние лимитера, кэш, отчёты спроса | workflow `seo-wordstat` |
| `reports/seo/intelligence/` | снапшоты, качество данных, письма V4, графики, журнал задач, site-check | сессия ежедневного отчёта, `seo-site-check` |
| `reports/seo/public/` | веб-отчёты | сессия ежедневного отчёта |

Обмен данными с рабочей копией main — `scripts/seo/data_sync.sh` (в main):
`pull` накатывает данные отсюда, `push` отправляет результаты сюда.

Правила:
- сюда не коммитится код; в main не коммитятся данные из этих каталогов;
- `reports/seo/wordstat/ledger/` — финансовый журнал, append-only, не переписывать;
- историю ветки допустимо схлопывать (squash) раз в месяц, сохраняя ledger
  целиком и месячный снимок `semantic-universe.jsonl`: полная история
  20-мегабайтного файла раздувает репозиторий на ~100 МБ в сутки.
