# Официальные логотипы производителей

Положите сюда официальные SVG-логотипы вендоров с именем файла по слагу:
`<slug>.svg` (например `adobe.svg`, `openai.svg`, `canva.svg`, `midjourney.svg`, `maxon.svg`).

Слаг — тот же, что в URL лендинга `/vendors/<slug>` (см. `src/data/vendors.ts`).

После добавления файлов выполните:

```
node scripts/build-logos.mjs
```

Логотипы из этой папки имеют приоритет над встроенным набором (simple-icons)
и рендерятся как `<img>` с фирменными цветами во всех местах сайта:
карусели на главной и в каталоге, hero лендингов, список `/vendors`.

Требования к файлу: самодостаточный SVG (без внешних ссылок), квадратный или
близкий к квадрату viewBox, оптимизированный (например, через SVGO).
