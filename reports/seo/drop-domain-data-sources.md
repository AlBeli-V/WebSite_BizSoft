# Замена источников после блокировки NameBright/DropCatch

Дата: 08.09.2026. Приложение к `reports/seo/drop-domain-strategy.md` и
`reports/seo/drop-domain-pilot-plan.md` (ворота G1); постановка источника —
`reports/seo/tasks/DATA-003-backlink-source.md`.

Повод: NameBright (Legal Department) отказал в восстановлении аккаунта,
блокировка объявлена постоянной и не пересматриваемой, создание новых
аккаунтов NameBright и DropCatch — прямо или косвенно связанных с тем же
лицом — запрещено.

---

## 1. Что именно отключилось

NameBright, DropCatch, HugeDomains и Expire.com принадлежат одной компании —
TurnCommerce. Значит, отключился не один сервис, а весь контур этой группы,
и «завести аккаунт на другое лицо или компанию» вариантом не является: письмо
прямо описывает такой аккаунт как подлежащий блокировке без уведомления, то
есть домены, купленные через него, оказались бы в аккаунте, который могут
закрыть в любой момент вместе с оплаченными позициями.

Функции, которые группа выполняла для доменного направления:

| Функция | Кто выполнял | Класс |
|---|---|---|
| Списки освобождающихся и pending delete доменов gTLD | DropCatch | данные |
| Перехват освобождающегося домена (backorder) | DropCatch | приобретение |
| Аукцион перехваченных доменов | DropCatch | приобретение |
| Регистратор и хранение пойманного домена | NameBright | владение |
| Витрина премиальных имён | HugeDomains | приобретение |

Источником данных для модели оценки кандидата
(`reports/seo/drop-domain-evaluation-model.json`) эта группа не была ни в
одном факторе: ссылочного профиля, анкоров, истории индексации и архивной
структуры URL она не отдаёт.

## 2. Что теряет от блокировки текущая работа

**По репозиторию — ничего.** Пилот по дропам не запущен решением
руководителя 08.09.2026 (`drop-domain-strategy.md`, раздел 12), оба ворота
не сработали: источника ссылочных и архивных данных нет (G1), индексный блок
не снят — Google не обходит 67% известных ему страниц (G2). Ни один рабочий
контур (`seo-serp-watch`, `seo-daily-report`, `competitive-intelligence-daily`,
`seo-wordstat`) на сервисы TurnCommerce не завязан: проверено грепом по
`scripts/`, `competitive-intelligence/`, `.github/workflows/` — упоминаний нет.

Поэтому вопрос стоит не «чем закрыть потерю качества», а «чем закрывать G1,
когда до него дойдёт дело»: потери качества нет, потому что качество на этих
источниках и не строилось.

## 3. Единственное срочное — домены в заблокированном аккаунте

Если в аккаунте NameBright есть активные домены (рабочие или ранее
купленные), это единственный срочный риск всей истории: при постоянной
блокировке доступ к панели и к трансферу может быть закрыт, а срок продления
продолжает идти. Регистратора `biz-soft.pro` в репозитории нет, проверить из
сессии нечем — ответ нужен от руководителя. Если домены там есть, порядок
действий отдельный: запрос на трансфер-аут с кодом авторизации, а при отказе
— обращение к аккредитующей стороне (ICANN Transfer Complaint), а не переписка
с самим регистратором.

## 4. Замена по функциям

| Функция | Замена | Качество против прежнего |
|---|---|---|
| Списки дропов gTLD, ручной просмотр | ExpiredDomains.net (бесплатно, свод по 676 TLD, включая аукционные площадки), WhoisFreaks (бесплатный ежедневный список), Instant Domain Search (раздел «dropping soon») | равно или выше: свод по многим площадкам вместо одной |
| Списки дропов, программно | DataForSEO Domain Analytics WHOIS API — фильтр по `expiration_datetime`, записи обогащены ссылочными и поисковыми метриками; при необходимости — зон-файлы ICANN CZDS и диффы по RDAP | выше: у DropCatch API отбора по качеству не было |
| Освобождающиеся `.ru` и `.рф` | cctld.ru (официальные списки), nic.ru, expired.ru (приём заявок для более чем десяти аккредитованных регистраторов) | новое покрытие: DropCatch зону `.ru` не обслуживал, а профиль донора BIZSoft — русскоязычный |
| Оценка кандидата по модели (ссылки, анкоры, доноры) | DataForSEO Backlinks API — тот же поставщик, аккаунт и секреты уже заведены (`DATAFORSEO_LOGIN/PASSWORD`, проба `ci-serp-probe`) | выше: сегодня не считается ни один фактор модели |
| Историческая структура URL, глубина архива | Wayback CDX API — бесплатно, без договора | выше: раньше не было |
| Присутствие в выдаче до дропа | xmlriver (Google) и Яндекс Search API — уже в контуре `seo-serp-watch` | равно |
| Глубокая ссылочная история (при нехватке первого источника) | Majestic: Trust Flow, Topical Trust Flow, исторический индекс, pay-as-you-go | выше по глубине, но это второй поставщик — против правила DATA-003 «один источник, один ряд» |
| Перехват gTLD | Dynadot, GoDaddy Auctions, SnapNames, NameJet, Pool, Sedo | ниже по вероятности перехвата конкурентных имён (у DropCatch была сеть из более чем тысячи аккредитаций); для нишевых имён профиля донора разница мала |
| Перехват `.ru` и `.рф` | expired.ru, Reg.ru, RU-CENTER | новое покрытие |
| Регистратор | Cloudflare Registrar, Porkbun, Namecheap, Dynadot; для `.ru` — Reg.ru, RU-CENTER, Timeweb | равно; оплата из РФ проще у российских |

## 5. Почему замена по данным получается сильнее прежнего

Обе половины ворот G1 — ссылочный индекс и архив — закрываются без нового
договора и без нового поставщика:

1. **DataForSEO уже подключён и оплачен.** Domain Analytics (WHOIS) и
   Backlinks — это те же учётные данные, что уже работают в
   Google-части конкурентной разведки. Один поставщик закрывает и ссылочные
   профили конкурентов из DATA-003, и историю доменов-кандидатов.
2. **Wayback CDX бесплатен** и закрывает архивную половину, которую DATA-003
   и разрешала брать отдельно.
3. **Отбор по качеству появляется до покупки.** У DropCatch поток был
   «имя + цена»; связка WHOIS-фильтра с ссылочными метриками даёт отбор по
   факторам модели ещё до аукциона.

Ограничение, которое нужно снять решением: у DataForSEO действует hard cap
**$20/мес** (`docs/competitive/decisions-2026-08-31.md`, раздел 3), и он
рассчитан под еженедельный съём Google-выдачи. Запросы Backlinks и WHOIS в
этот потолок не закладывались — либо потолок поднимается, либо заводится
отдельная строка бюджета с собственным счётчиком в журнале.

## 6. Что решает руководитель

1. Есть ли активные домены в заблокированном аккаунте (раздел 3).
2. Закрывать G1 существующим поставщиком или заводить отдельный ссылочный
   сервис (раздел 4, строки про DataForSEO и Majestic).
3. Восстанавливать ли сейчас канал приобретения (перехват и регистратор) или
   отложить до срабатывания обоих ворот пилота.
