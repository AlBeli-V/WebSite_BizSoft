# DATA-003 — Источник ссылочных и архивных данных

**Приоритет:** P1 · **Статус:** решение принято 08.09.2026, подключение не выполнено · **Владелец:** руководитель (оплата и доступ) · **Обновлено:** 2026-09-08

## Почему заведён

Разбор Google-авторитета (`reports/seo/google-authority-strategy.md`) упёрся
в отсутствие данных ровно в двух местах, и оба относятся к оценке чужих
доменов, а не своего:

1. **Ссылочные профили конкурентов** (этап 7 задания): referring domains,
   распределение анкоров, dofollow/nofollow, типы ссылок, редакционные
   упоминания. Search Console отдаёт ссылки только на собственный сайт,
   конкурентов не видит. Из-за этого раздел 7 отчёта содержит только
   разрыв по видимости в выдаче, а не по ссылочному профилю.
2. **История доменов-кандидатов** для оценки дропов: ни один фактор модели
   `reports/seo/drop-domain-evaluation-model.json` сегодня не считается.
   Это первое из двух ворот пилота (G1).

Решение руководителя 08.09.2026: **подключить один источник сейчас**, не
откладывая до конца волны 1.

## Что нужно от источника

Обязательный минимум — без него подключение не закрывает задачу:

| Данные | Для чего |
|---|---|
| Ссылающиеся домены по произвольному домену (не только своему) | ссылочный разрыв с конкурентами |
| Распределение анкоров | оценка профиля и планка для собственного |
| dofollow / nofollow | классификация ссылок |
| Динамика: появление и потеря ссылок | замер эффекта внешнего слоя |
| История домена: темы, смены владельца, следы редиректов | отбор дроп-кандидатов |
| Выгрузка (API или CSV) | чтобы данные попадали в контур, а не оставались в кабинете |

Архивные данные (историческая структура URL) допустимо закрывать отдельным
бесплатным доступом к веб-архиву — это не обязательно тот же поставщик.

## Что делает сессия после подключения

1. Базовый замер: ссылочный профиль biz-soft.pro на дату подключения —
   это точка отсчёта, без неё эффект внешнего слоя недоказуем.
2. Профили десяти фактических конкурентов Google из
   `reports/seo/google-link-gap.csv` (platipomiru.com, oplata.guru,
   raketapay.ru, wanttopay.net, pay-saas.ru, exnode.ru, mshopy.ru,
   payholder.ru, syssoft.ru, getpayall.com).
3. Дозаполнение колонок ссылочного профиля в `google-link-gap.csv` и
   снятие соответствующей строки из раздела «Пробелы данных» отчёта.
4. Расчёт: каких категорий ссылочного авторитета у BIZSoft нет вовсе.

## Чего делать не нужно

Подключать два источника «для сверки». Расхождение между ссылочными
индексами — известное свойство, а не ошибка; сверка съест бюджет и не даст
решения. Один источник, один ряд, сравнение внутри него.
