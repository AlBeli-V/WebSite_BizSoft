# ANL-004 — Завести конверсионные цели в счётчике Метрики и GA4

**Приоритет:** P0 · **Статус:** open · **Заведено:** 2026-08-21 · **Созревает:** 2026-09-09

> **Правка 08.09.2026 (разбор money-запросов).** В шапке стояло «исполняется
> руками в интерфейсах — кодом не закрывается». Это перестало быть правдой
> 04.09.2026: в тот день в проект добавлен `scripts/seo/goals_sync.py` и
> workflow `seo-goals-sync` — они читают реестр `src/lib/analytics.ts` и
> заводят недостающие цели в Метрике и ключевые события в GA4 по API. Инструмент
> появился на две недели позже тикета, и его появление в шапке не отразилось:
> P0 остался лежать с пометкой, что закрыть его нечем.
>
> Руками остаётся не всё, а часть: фильтр внутреннего трафика GA4 и
> custom dimensions (разделы ниже) — их API `goals_sync.py` не трогает.
>
> Порядок: `seo-goals-sync` с `apply=false` показывает, чего не хватает,
> ничего не меняя; затем тот же workflow с `apply=true` заводит перечисленное.
> Скрипт ничего не удаляет — снятая по ошибке цель обнуляет историю.
>
> Решение о запуске с `apply=true` — за владельцем контура: это запись в боевые
> кабинеты аналитики.

## Почему это блокирует всё остальное

Пока целей нет, конверсия сайта не измеряется вообще: ни один канал, ни одна
страница, ни один эксперимент не могут быть оценены по обращениям. Это делает
неполными выводы любого контура, включая разбор money-запросов от 08.09.2026 —
там весь счёт идёт в переходах, потому что обращений в данных нет.

## Проблема

Сайт отправляет 23 имени целей. В счётчике 110206070 заведено 4 цели, и все
четыре — автоцели. Пересечение множеств пустое: каждый вызов `reachGoal`
счётчик отбрасывает. В GA4 ключевыми событиями размечены `form_submit` и
`generate_lead` — сайт не отправляет ни одно из них.

Следствие: конверсия сайта не измеряется вообще. Ни один канал, ни одна
страница, ни один эксперимент не могут быть оценены по обращениям.

Вторая причина, зафиксированная в реестре пределов раньше — вырезание вызовов
минификатором — **устранена**: `src/lib/analytics.ts` задаёт непустой фолбэк
идентификатора, и код остаётся достижимым. Остаётся единственная действующая
причина: целей нет в счётчике.

## Что сделать

**Яндекс.Метрика, счётчик 110206070.** Завести JavaScript-цели:

| Идентификатор цели | Что означает | Уровень |
|---|---|---|
| `lead_sent` | сервер принял заявку (HTTP 200 от `/api/lead`) | lead |
| `quote_pdf` | КП сформировано и отправлено | lead |
| `add_to_cart` | товар добавлен в подборку | micro |
| `form_start` | начато заполнение формы | micro |
| `contact_click` | клик по телефону, почте, Telegram, WhatsApp | intent |
| `click_get_quote` | клик по CTA «получить КП» | intent |

Цели уровня `engagement` (просмотры лендингов, клики по карточкам) целями
**не делать**: список целей должен оставаться списком того, что важно для
бизнеса, иначе им перестают пользоваться.

**GA4, property 543500233.** Разметить как key events `lead_sent` и
`quote_pdf`. Снять пометку с `form_submit`: он приходит из enhanced measurement
и срабатывает на **попытку** отправки — формы вызывают `preventDefault` и шлют
`fetch`, поэтому событие возникнет и при отказе сервера с кодом 422.

**GA4, фильтр внутреннего трафика.** Завести Internal Traffic по IP офиса и по
параметру `?internal=1`; добавить `metrika.yandex.ru`, `webmaster.yandex.ru`,
`alice.yandex.ru` в список исключаемых рефереров.

**Custom dimensions GA4** (event-scoped): `sku`, `vendor`, `form_source`,
`block_name`, `channel`. Без регистрации параметр не появляется в стандартных
отчётах и недоступен Data API — передачи параметра в событии недостаточно.

## После выполнения

Проставить дату в `reports/seo/measurement-limits.json`, записи ANL-001 и
ANL-002. Дата становится границей сравнения: конверсии через неё не
сравниваются, а рост после заведения целей — восстановление измерения, а не
результат работ.

## Проверка

1. `GET /management/v1/counter/110206070/goals` — имена целей содержат все шесть.
2. Проверка `GOAL_NOT_CONFIGURED` в `scripts/seo/quality.py` перестаёт срабатывать.
3. Тестовая заявка на проде появляется в отчёте «Конверсии» в течение суток
   и одновременно в Directus — обе стороны, а не одна.
