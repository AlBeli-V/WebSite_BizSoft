# SEO-EXP-001 — Совместное изменение карточек вендоров (заголовки + блок вопросов)

**Приоритет:** P0 · **Статус:** running (деплой 2026-08-19) · **Владелец:** не назначен (DEC-002)

## Scope
Одно совместное внедрение 2026-08-19: заголовки, описания и блок вопросов пяти страниц.
Изменения выкачены одновременно, поэтому оцениваются как **один эксперимент**; ретроспективное
разделение на два независимых эксперимента запрещено — вклад элементов неразделим по построению.
Страницы:
`/vendors/canva`, `/vendors/depositphotos`, `/vendors/coreldraw`, `/vendors/heygen`, `/vendors/marmoset`.
Раздельная оценка вклада блока вопросов возможна только в будущем изменении (CRO-EXP-002),
на новых страницах или в новом временном окне.

## Статус
Внедрено 2026-08-19, наблюдение до 2026-08-26. Владелец роли: SEO Lead. Требуется зафиксировать
дату фактического появления обновлённого сниппета в выдаче.

## Требования
- Контрольная группа: остальные vendor-страницы без изменений; состав зафиксировать списком.
- Baseline до внедрения: значения показов/кликов/позиций за сопоставимое окно до 2026-08-19.
- Работа только в feature-ветке + pull request; автодеплой не запускать.
- URL не менять.
- Коммерческие утверждения в сниппете (счёт, договор, ЭДО, сроки) сверить с утверждённым источником
  условий; при отсутствии подтверждения — переформулировать.
- Полный title оценивать вместе с брендом; число символов не является единственным критерием.
- Зафиксировать отдельно: дату деплоя и дату, когда обновлённый сниппет фактически появился в выдаче
  (проверять через воркфлоу `seo-site-check` и выдачу).

## Метрики
- Primary: CTR с поправкой на позицию — при наличии утверждённой CTR-модели; иначе CTR с обязательным
  контролем средней позиции и состава запросов.
- Guardrails: показы, средняя позиция, органические сессии, уникальные пользователи с целевым событием.

## Правило вывода
Результат не объявляется по фиксированному сроку 7 дней. Условие оценки: достигнут минимальный объём
наблюдений (определить до старта измерения) либо закрыто окно 28 дней. При недостаточной мощности
публикуется описательный вывод с доверительным интервалом, без вердикта.
