## Что сделать

Статьи по схеме CONTENT-001 (приём подтверждён вердиктом 02.09: +70 % показов
кластера Depositphotos и вход статьи в топ-10) под фактические запросы этих
кластеров. **Партиями по 4–5 кластеров**, чтобы партия проходила порог
экспозиции целиком, а не по одной странице.

Первая партия по сумме показов и позиции: gaea, zoho, hailuo, houdini, foundry
(165 показов, 13,8 в день — порог пройден).

Текст писать по skill `bizsoft-content`. Перед заведением —
`python3 scripts/seo/experiment_windows.py validate`.

## Зачем это, а не сниппеты

Конфликта с идущими экспериментами нет, порог проходится составом партии, и это
единственная работа из очереди, которая увеличивает показы, а не пытается
выжать переходы из тех, что есть.

## Этап и ветка

Решение руководителя 08.09.2026: работа идёт **отдельной веткой**
`claude/money-005-content-wave`, не в ветке модели. Причина: это пять статей по
редполитике, и класть их в один дифф с правкой шаблона и моделью — значит
отдавать на ревью то, что нельзя проверить по частям и нельзя откатить по
частям.

Начало этапа:

```
git fetch origin main && git checkout -B claude/money-005-content-wave origin/main
```

Перед заведением эксперимента — `python3 scripts/seo/experiment_windows.py validate`.
Перед первой строкой текста — skill `bizsoft-content`: там накопленная
редполитика, банк подтверждённых фактов и разборы прошлых ревью.

Оговорка по срокам: замер MONEY-006 ещё не сделан, и его исход может поменять
приоритет всей контентной программы. Если замер покажет, что органика лежит
