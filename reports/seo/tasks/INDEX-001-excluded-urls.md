# INDEX-001 — Классификация исключённых URL

**Приоритет:** P1 · **Статус:** open

## Контекст
Яндекс.Вебмастер: 169 URL в поиске, 32 исключено (снимок 2026-08-19). Причины не выгружаются —
проверка `INDEXATION_UNCLASSIFIED`. Само по себе исключение не является проблемой.

## Задача
1. Проверить фактический контракт API Вебмастера (конкретный endpoint, параметры, лимиты) —
   не использовать формулировку «endpoint A и/или B» без теста.
2. Добавить в `scripts/seo/collect.py` выгрузку исключённых URL с причинами: retries,
   обработка rate limit, сохранение исходного ответа, fixture для тестов.
3. Классифицировать: ожидаемо исключённые · дубли · редиректы · canonical · noindex ·
   технические ошибки · коммерчески важные страницы · не классифицировано.

## Приоритизация
Определяется числом коммерчески значимых URL, а не общим количеством исключений.

## Результат
`reports/seo/excluded-pages-analysis.md` + поле `excluded_by_reason` в snapshot.
