# MONEY-010 — Запросы кластера Zoom в ядро seo-serp-watch

**Приоритет:** P3 · **Статус:** queued · **Заведено:** 2026-09-08 · **Созревает:** 2026-09-15

## Проблема

`/vendors/zoom` входит в партию MONEY-A1, но среза выдачи по её кластеру нет:
запросы «оформление zoom business для организации из рф» (35 показов) и
«купить zoom pro юридическим лицом» (6) в срез `2026-09-08-serp.jsonl` не
попали. Сниппет сравнить с соседями было нечем — правка на этой странице
обоснована беднее, чем на двух других, и вывод по ней будет опираться только
на CTR.

## Что сделать

Проверить, что запросы кластера попали в ядро (`scripts/seo/serp_watchlist.py`
строит его из снимка дня, экспозиции 4,0 показа в день для порога
`MIN_IMPRESSIONS = 3` хватает с запасом). Если через неделю их всё ещё нет —
разобраться почему: либо снимок, из которого строится ядро, старше выгрузки,
либо запросы отсекаются классификатором интента.

Проверка: `grep -c 'zoom' reports/seo/serp/<дата>-serp.jsonl` в ветке seo-data.
