# DATA-002 — Дневной ряд Яндекс.Вебмастера

**Приоритет:** P2 · **Статус:** open

## Проблема
График «Яндекс: динамика показов и кликов по дням» не может быть построен: текущий сбор использует
endpoint популярных запросов, который отдаёт агрегат за окно без разбивки по дням.

## Задача
Добавить выгрузку истории показов/кликов по дням (проверить фактический контракт API, сохранить
исходный ответ, добавить fixture) и построить график с 7-дневной скользящей средней и отметками
внедрений.

## Результат
Поле `daily` в блоке `yandex` snapshot и график `<дата>-yandex-daily.svg`.
