## 7. Минус-слова

Работает: блок «бесплатно/скачать/торрент/кряк/студент/школьник» — ни
одного клика с этими словами; «пробный/триал» — чисто.

Не работает и почему:

1. **Минусы бессильны против запросов без минус-слов** — весь мусор дня
   («что это», «джипити», «для создания картинки логотипа», голый
   «midjourney») прошёл законно: механика Директа исключает запрос только
   при наличии в нём минус-слова. Защита от такого мусора — не минусы,
   а ограничение автотаргетинга.
2. **Дыры в списке**: «free» («free claude code»), «дешево» («claude pro
   дешево») отсутствовали, хотя «бесплатно» и «халява» есть.
3. **Морфология**: «бесплатно/бесплатный/бесплатная» — избыточные
   дубли (Директ матчит словоформы), вреда нет, но список раздут.
4. **Перерез**: «аккаунт» уничтожил семантику «купить аккаунт …» (v3,
   сознательно); «картой» блокирует «оплатить картой» — для юрлиц по
   счёту это осознанный фильтр, оставить.

Архитектура (предложение): глобальный список (пиратство, халява, работа,
обучение) — на кампанию; интент-фильтры B2C («личный», «себя», «студент»)
— на кампанию; бренд-омонимы (cloud для Claude Code, самокаты для Slack
при расширении) — на группу. Каждое новое минус-слово проверять по
Вордстату на пересечение с коммерческими фразами.
