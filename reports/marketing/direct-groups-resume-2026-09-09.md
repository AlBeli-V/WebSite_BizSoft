# Возврат групп Claude и Claude Code — 2026-09-09

Решение руководителя 09.09.2026 по итогам разбора замера кампании
bs-test-2026-09.

## Что было

Спецификация раунда 2 (`round2-spec.json`, применена 03.09) остановила
три группы по стоп-правилу «клики есть, заявок нет»:

| Группа | Факты на момент паузы |
|---|---|
| Claude Code — для команд разработки | 77 кликов, 654 ₽, 61 визит, 0 заявок |
| ChatGPT Business — гипотеза с фильтром до клика | 42 клика, 817 ₽, 36 визитов, 0 заявок |
| Claude — подписки для компаний | 24 клика, 422 ₽, 14 визитов, 0 заявок |

## Почему решение пересмотрено

Критерий «ноль заявок» измерялся сломанным инструментом. Разбор воронки
07.09 (`lead-funnel-experiment-2026-09-07.md`) установил три независимых
дефекта приёмки, действовавших всё это время:

1. событие открытия формы не отправлялось вовсе — по нулю нельзя было
   отличить «не дошли до формы» от «открыли и не стали заполнять»;
2. цель клика по главному призыву не значилась в реестре, уходила в
   счётчик и пропадала — в кабинете её не существовало;
3. заявка требовала открыть модальное окно и назвать семь реквизитов
   сразу, на первом же контакте.

Сверх того счётчик Метрики не писал визиты с 05 по 07.09
(`metrika-outage-2026-09-08.md`): за эти сутки данных нет вообще.

Ноль заявок в такой обстановке — свойство измерения, а не трафика.
Стоп-правило сработало на показании неисправного прибора.

## Что сделано

Возвращены две группы из трёх (`ops-direct action=resume`):

- **Claude — подписки для компаний** и **Claude Code — для команд
  разработки**. Обе ведут на `/vendors/anthropic` — ту самую страницу,
  где 07.09 появилась форма в первом экране. Без них замер воронки
  питается одной группой Adobe.
- Claude Code вдобавок самая дешёвая группа кампании: 11,7 ₽ за клик
  при CTR 9 % против 24 ₽ в среднем по кампании.

**ChatGPT Business остаётся на паузе**: второй ценник кампании (28,2 ₽)
при самом низком CTR, посадочная в число страниц с новой формой не
входит — к идущему замеру он ничего не добавит.

Спецификация раунда 2 приведена в соответствие: обе группы перенесены из
`pause` в `keep` (`spec_version` r2-v3), прежние причины паузы сохранены
в тексте. Иначе повторное применение спецификации остановило бы их
снова.

## Состав кампании на время замера воронки

Решение руководителя 09.09: состав остальных групп не меняем. Форма в
первом экране выкачена только на `/vendors/anthropic` и `/vendors/adobe`,
прочие активные группы ведут на страницы без неё — эта разница работает
как естественное сравнение. Через две недели будет видно, отличаются ли
страницы с формой от страниц без неё на одном и том же трафике.

Первый сигнал уже есть: 08.09 при шести визитах кампании цель «Форма
заявки открыта» сработала четыре раза, все на страницах с новой формой.

## Что не менялось

Ставки, недельный лимит и стратегия не трогались. Потолок цены клика
стоит с 04.09 на 30 ₽ без НДС (≈37 ₽ с НДС) — проверено прогоном
`ops-direct action=ceiling` в режиме dry-run 09.09: значение на месте,
менять нечего.
