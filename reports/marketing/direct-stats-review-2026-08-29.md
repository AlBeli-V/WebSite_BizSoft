### 3. «Просмотры без переходов и без запросов КП» — что это значит

- CTR 13 % — это не «показы без переходов»: кликают хорошо. Нулевые клики —
  у фраз (3 показа) и в интерфейсных срезах по фразам; смотреть эффективность
  надо по условиям показа, там работает только автотаргетинг.
- Запросов КП и заявок нет — на 18 кликах это статистически ожидаемо:
  при плановой конверсии 1–2 % на 18 кликов приходится 0,2–0,4 события.
  Порог первого вывода по спецификации — 12 кликов на группу; ни одна группа
  его не набрала (по 6).
- Но качество визитов низкое и это уже видно: 75 % отказов, 1,38 стр./визит.
  Причина согласуется с п. 2 — половина кликов нецелевые.
- «15 конверсий» в отчёте Директа — сумма всех целей счётчика, включая
  автоцели и diagnostic-события (переходы по страницам, вовлечённость).
  По правилу спецификации diagnostic-события не считаются результатом.
  Первичных событий (заявка, запрос КП с контактами) — 0.

## Что предлагаю (изменения кампании — только по вашему поручению)

1. **Обуздать автотаргетинг, не выключая его целиком** — он единственный
   источник данных: в настройках групп оставить только категорию «целевые
   запросы» (выключить широкие/альтернативные/сопутствующие), и добавить
   минусы по фактам: «что это», «free», «дешево», «cloud», «сметчик»,
   «ходатайство», «логотип», «картинки», «яндекс», «системные требования»,
   «попробовать». Голый «midjourney» — решить: это контрольная корзина,
   но она уже съела треть кликов; предлагаю минус-фразу «!midjourney» без
   добавок оставить только в одной группе с ограниченной ставкой.
2. **Расшить фразы**: снять кавычки с 6–8 ядровых («claude купить»,
   «claude pro купить», «chatgpt business купить», «midjourney купить»,
   «claude code купить»), оставив +операторы и защиту минусами. Иначе
   тест меряет автотаргетинг, а не наши гипотезы.
3. **Посадочная Claude Code**: запросы «claude code …» ведут на
   /vendors/anthropic; для интента разработки уместнее карточка продукта
   Claude Code / раздел тарифов — проверить после набора кликов.
4. **Не трогать оффер и бюджет по итогам одного дня**: стоп-правила не
   сработали, недельный лимит 4098 ₽ при темпе ~590 ₽/4,5 ч сам ограничит
   открутку к середине недели.
5. **Разночтение метрик**: в интерфейсе Директа не считать «конверсии»
   результатом — сверяться с Метрикой по целям lead_sent / quote_pdf
   (первичные) и с воронкой CRM.
