## 2. Логика выбора кампаний

Критерий «максимум конверсий за минимум денег»:

1. **Узкий транзакционный интент дешевле широкого брендового.** «оплатить
   claude на юрлицо из россии» стоит в разы дешевле «adobe купить», а
   конвертирует лучше — человек ищет ровно нашу услугу.
2. **Оффер уникален** — «оплата на юрлицо: счёт, договор, ЭДО, рубли,
   доступ 1–3 дня». По широким запросам мы конкурируем с ресейлерами, по
   «оплате из России» — почти нет.
3. **Растущий тренд** (AI-кластеры) и **готовая посадочная**.
4. **Регулярный чек**: подписки (Claude, Cursor, OpenAI) дают повторные
   платежи — LTV оправдывает более высокий CPL.

Поэтому Adobe и Gemini — большие, но дорогие и (adobe — стабильный, google —
замусоренный интент «купить аккаунт») — во **вторую волну**, после проверки
связки «клик → лид» на дешёвых сегментах.

## 3. Ограниченный перечень кампаний эксперимента

### К1 «AI-подписки для юрлиц» — приоритет 1

- Семантика: claude купить (на юрлицо / подписку / team / pro), оплатить
  claude из россии, cursor подписка / купить / оплатить, chatgpt team на
  компанию, openai api оплата. Суммарный спрос ядра ≈ 35 000 показов/мес.
- Посадочные: /vendors/anthropic, /vendors/cursor, /vendors/openai.
- Оферты: **Claude Team**, **Cursor Business**, **ChatGPT Team / OpenAI API** —
  оплата по счёту в рублях, договор, ЭДО, доступ 1–3 дня.

### К2 «Оплата зарубежных сервисов» — приоритет 2 (нужна посадочная)

- Семантика: оплата зарубежных сервисов (из россии, для юрлиц, подписок) —
  15 947 показов/мес, растёт, конкуренция услуговая, не продуктовая.
- Посадочной нет (GAP-A). До запуска сделать страницу услуги (заготовка —
  статья blog/kak-kupit-zarubezhnoe-po-dlya-yurlica). Если страницу не
  делаем — К2 откладывается, запускаем К1+К3.
- Оферта: оплатим любой зарубежный сервис на вашу компанию; условия,
  сроки, документы.

### К3 «Горячая выдача: узкие бренды» — приоритет 3, самая дешёвая

- Семантика: оплата depositphotos / canva / coreldraw / heygen / recraft
  для юрлиц, по счёту, из россии — ровно те фразы, где Вебмастер уже
  показывает нас в топ-3–6. Частотность мала, зато CPC минимален и интент
  чистый.
- Посадочные: /vendors/depositphotos, /vendors/canva, /vendors/coreldraw,
  /vendors/heygen, /vendors/recraft.
- Оферты: пакеты Depositphotos, Canva Teams, CorelDRAW Graphics Suite,
  кредиты HeyGen/Recraft.
- Побочная ценность: платный трафик на эти страницы даст быстрые данные о
  конверсии посадочных, которые проверяет SEO-EXP-001/002.

### Общие настройки

- Тип: поисковые кампании (не РСЯ на старте — экономим на нецелевых показах).
- Стратегия ставок: «Максимум конверсий» **с оплатой за конверсию**, цель —
  lead_sent (вторая — quote_pdf). Платим только за лид: это и есть
  «максимум конверсий за минимум денег», плюс защита от скликивания.
- Гео: Россия. Время: круглосуточно, корректировки после первой недели.
  Все расписания — по Москве.
- Минус-слова (из данных Вордстата обязательно): бесплатно, скачать,
  торрент, crack, взлом, активатор, курс, обучение; для claude — monet,
  моне; для slack (если возьмём) — core 920r, самокат, электросамокат;
  aws в семантику НЕ брать («aws купить» = автоприсадка, стиральные машины).
  Омонимы box / zoom / bubble в широкие фразы не включать.
- UTM: не нужны — атрибуция ловит yclid автоматически, но utm_campaign
  проставить для читаемости отчётов.

## 4. Бюджет

CPC-прогноза в наших данных нет (API Директа не подключён) — до запуска
снять «Прогноз бюджета» в интерфейсе Директа по трём пакетам семантики и
вписать сюда. Каркас:

| Параметр | Значение |
|---|---|
| Длительность | 2 недели (минимум для стратегии с оплатой за конверсию) |
| Дневной потолок | К1 — 1 000 ₽; К2 — 700 ₽; К3 — 500 ₽ |
| Максимальный расход | ≈ 31 000 ₽ за 2 недели (фактический при CPA-оплате будет ниже) |
| Цена конверсии (tCPA) | стартово по прогнозу Директа; потолок — от маржи оффера, поле руководителя: ___ ₽/лид |
| Мин. объём для выводов | ≥ 10 лидов суммарно, иначе продлеваем, а не режем |

Stop-условия:

1. Кампания потратила 50 % двухнедельного бюджета без единого lead_sent /
   quote_pdf → пауза, разбор посадочной и объявлений.
2. CTR на поиске < 1 % → переписать объявления (не трогая ставки).
3. Итог 2 недель: CPL по кампаниям из CRM (стадии, а не сырые лиды);
   всё с CPL выше потолка — стоп, лучшую кампанию масштабируем ×2 бюджета.
4. Внутри кампаний A/B не делить — мощности нет; сравниваем кампании
   между собой.

## 5. Чек-лист перед запуском

1. Решение руководителя: снять blocked_by_policy с PPC-RES-001 (RED-зона).
2. Прогноз бюджета Директа по семантике К1–К3 → вписать CPC/объёмы сюда.
3. Подтвердить по письму seo-analytics-check, что цели принимают события
   (наблюдение с 21.08).
4. Посадочная для К2 (или запуск без К2).
5. Задать tCPA-потолок от маржи (поле в разделе 4).
6. Выставить дневные лимиты и общий cap в Директе.

## 6. Что НЕ запускаем и почему

- **Adobe, Google/Gemini** — вторая волна: дорогая конкуренция, у adobe
  тренд стабильный (не убежит), у google высока доля мусорного интента.
- **AWS** — омоним (автохимия/техника), спрос не наш.
- **Unity, Autodesk** — санкционно-чувствительные вендоры с долгим циклом
  сделки; после проверки связки на К1–К3.
- **РСЯ, ретаргетинг** — после накопления аудиторий счётчиком (трафик пока
  ~19 визитов/нед, ретаргетить некого).
