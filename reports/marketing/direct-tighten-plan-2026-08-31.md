## 2. Расширение ежедневной статистики (ops-direct (action=stats))

Закрывает пункт P1 аудита («Conversions» без разбивки) и «поведение
одним средним числом»:

- **Кандидаты в фразы**: A/B-запросы автотаргетинга с кликами теперь
  печатаются отдельным списком каждый день — ежедневная лента механизма
  P3, решение о переносе остаётся за владельцем.
- **Метрика: конверсии кампании по целям** — визиты кампании (фильтр по
  utm_campaign, резерв — атрибуция Директа), достижения в разбивке по
  всем целям счётчика: видно, какие именно цели дают «45 конверсий»
  интерфейса и есть ли среди них lead_sent / quote_pdf.
- **Метрика: поведение по поисковым запросам** — визиты, отказы,
  глубина, время на сайте по каждому запросу кампании.
- **Метрика: поведение по посадочным** — то же в разрезе страниц входа.

Разделы Метрики опциональны: без секретов или при недоступном атрибуте
печатается причина, сбор Директа не прерывается. Секреты
`YANDEX_METRIKA_TOKEN` / `YANDEX_METRIKA_COUNTER_ID` уже есть в
репозитории (используются seo-analytics-check).

## Порядок применения

1. Слить пакет в main.
2. Actions → **ops-direct (action=tighten)** → ветка main → `mode=dry-run` —
   сверить план по журналу issue #22.
3. Там же `mode=apply`.
4. Следующий штатный прогон ops-direct (action=stats) (07:10 МСК, будни) покажет
   новые разделы; эффект затяжки оценивать со вторника-среды.

  на очищенном трафике.
