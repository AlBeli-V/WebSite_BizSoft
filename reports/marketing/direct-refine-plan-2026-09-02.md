## 2. Главный вывод: «кандидат на паузу» сейчас не значит «не работает»

Письмо помечает три направления как кандидатов на паузу: Claude Code
(77 кликов), ChatGPT Business (41), Adobe (37) — все с нулём заявок.
Порог `stop_clicks` в `scripts/seo/ads_block.py` задан вручную:
12 для ChatGPT, 20 для Adobe, 25 для Claude Code, 40 для Claude.
Эти числа ни из чего не выведены, и на них нельзя останавливать группы.

**Проверка вероятностью.** Если реальная конверсия клика в заявку равна
целевым для B2B 2 %, вероятность увидеть ноль заявок равна (1−CR)ⁿ:

| Направление | Кликов | P(0 заявок) при CR 2 % | при CR 3 % | Верхняя граница CR (95 %) |
|---|---|---|---|---|
| Claude Code | 77 | 21 % | 10 % | ≤ 3,9 % |
| ChatGPT Business | 41 | 44 % | 29 % | ≤ 7,3 % |
| Adobe | 37 | 47 % | 32 % | ≤ 8,1 % |
| Вся кампания | 180 | 2,6 % | 0,4 % | ≤ 1,7 % |

Читается так: на 37–77 кликах ноль заявок — обычный исход даже у
здоровой группы, и данные не отличают конверсию 0 % от 4–8 %. Значимость
появляется только на уровне всей кампании: там ноль на 180 кликах уже
говорит, что средняя конверсия ниже 2 %, но не исключает 1 % (при 1 %
ноль заявок ожидался бы в 16 % случаев) — а 1 % при нашем чеке
рентабелен.

**Проверка деньгами.** Порог допустимого CPA заявки задан в том же
файле: 1500–3000 ₽ по направлениям (≈25 % прибыли сделки). Группа
становится убыточной не на N кликах, а когда потратила свой CPA-лимит
без единой заявки. Отсюда экономически честный порог паузы —
`stop_clicks = cpa_limit / CPC`:

| Направление | CPA-лимит | CPC | Порог по деньгам | Порог в письме | Кликов сейчас |
|---|---|---|---|---|---|
| Claude | 3000 ₽ | 15 ₽ | ~200 | 40 | ~15 |
| Claude Code | 3000 ₽ | 11 ₽ | ~270 | 25 | 77 |
| ChatGPT Business | 2500 ₽ | 21 ₽ | ~120 | 12 | 41 |
| Cursor | 3000 ₽ | 19 ₽ | ~160 | 25 | 4 |
| Adobe | 1500 ₽ | 9 ₽ | ~165 | 20 | 37 |
| Midjourney | 600 ₽ | ~15 ₽ | ~40 | 25 | 6 |

Ни одно направление не подошло к своему порогу по деньгам. Вся кампания
за четыре дня потратила меньше, чем CPA-лимит одной группы Claude Code.
Пауза сейчас останавливала бы эксперимент до того, как он стал возможен.

## 3. Что при этом действительно доказано данными

Поведение по запросам различает трафик там, где заявок ещё нет:

- голый «claude code» — 65 % отказов, глубина 1,00, 16 секунд, ноль
  целей на 31 визите;
- «claude code enterprise» — 87 секунд, 2 страницы; «claude code купить»

То есть отбирать надо не группы целиком, а интенты внутри них. Затяжка
31.08 это подтвердила: доля мусора упала вдвое, расход по трём главным
утечкам перестал расти, трафик перетёк в коммерческие фразы (CPC вырос
с 11,5 до 16,9 ₽, CTR упал с 8,8 до 5,6 % — ожидаемая плата за уход
дешёвого кликабельного мусора).

### 4.2 Минус-фраза группы Claude Code: «команды для»

Запрос «команды для claude code» (17,03 ₽) — справочник команд, не
покупка. Одиночным словом `команды` его брать нельзя: лемма та же, что
у собственной фразы «claude code +для команды» — первой B2B-фразы,
давшей клик после затяжки. Минус-фраза срезает «команды для claude
code», но не «claude code для команды разработки»: в минус-фразах
Директа порядок слов значим.

Ошибка такого рода не видна глазом, поэтому она проверяется машиной:
`direct_refine.py` перед изменениями читает все ключевые фразы кампании
и падает, если минус задевает собственную семантику (сверка по корню
слова, не по написанию). Проверка закреплена тестами
`scripts/seo/tests/test_direct_refine.py`.

### 4.3 Перенос запросов в фразы (механизм P3 «запрос → ключ»)

Кандидат «клод код нейросеть купить» взят не дословно: слово

- **Ставки, бюджет, стратегия, расписание** — не трогаются.

## 5. Что остаётся неизвестным и как это закрыть

Ноль заявок при 150 визитах кампании не разделён на две разные болезни:
до формы не доходят (вопрос к офферу и посадочной) или упираются в саму
форму (вопрос к форме). Разводит их цель `form_start`, которая уже стоит
в `LeadForm.astro`: её наличие при нулевом `lead_sent` означает трение в
форме, отсутствие — что до формы не добираются. Разбивка по целям есть в
`ops-direct (action=stats)` — смотрим на следующем замере.

Отдельная проверка: 01.09 сработала автоцель Метрики «отправка формы»
при нулевом `lead_sent`. Код целей корректен (`lead_sent` уходит после
успешного ответа `/api/lead`, сбой ловится в `lead_error`), а автоцель
Метрики срабатывает на submit любой формы, включая поиск и форму КП, —
то есть объяснение штатное. Но пока в разбивке нет `lead_error`, версию
«заявка была, цель не долетела» полностью снимать нельзя.

## 6. Ожидаемый эффект пакета

- Класс C сейчас — около 25 % расхода, это ~160 ₽ в день. Пакет
  адресует ~60 ₽/день фактически замеченных запросов; при обычном
  расползании семантики экономия выше, но обещать больше нечего.
- Четыре новые фразы работают в обратную сторону — добавляют
  коммерческий трафик там, где он уже показал себя.
- Порог решения по паузам — не раньше выхода направления на его
  CPA-лимит: Claude Code ~270 кликов, Adobe ~165, ChatGPT ~120. При
  нынешнем темпе это 3–5 дней открутки.

### Первый экран: что именно поменялось и почему

Замер 04.09 развёл посадочные по типу страницы:

| Посадочная | Тип | Визиты | Отказы |
|---|---|---|---|
| /vendors/openai | bespoke | 23 | 22 % |

Разница ровно в первом экране: у bespoke-страниц (openai, figma,

с посадочной ровно тех, кто пришёл по рекламе за конкретным продуктом.

Изменения типового лендинга (`VendorGenericLanding.astro`): строка
«Цены от X ₽ в год · N позиций в каталоге» в первом экране, вторая

`tests/vendor-landing-first-screen.test.ts`.

Правка покрывает 151 из 226 визитов кампании (anthropic + adobe идут
через типовой лендинг). Bespoke-страницы уже устроены так и не трогались.

### Потолок цены клика

Кампания идёт на автостратегии «максимум кликов»: ставки по фразам
вручную не задаются, штатный рычаг один — `BidCeiling` на уровне
стратегии. Порог 30 ₽ без НДС (≈36,6 ₽ с НДС в отчётах) отсекает хвост —
«claude code купить» 69,76 ₽, «cursor купить» 55,74 ₽, «claude купить
подписку» 50,97 ₽, автотаргетинг ChatGPT 36,87 ₽ — и оставляет основную
массу: средняя цена клика накопительно 21,27 ₽ с НДС, то есть 17,4 ₽ без
НДС, порог выше неё в 1,7 раза.

Скрипт переписывает стратегию целиком (Директ принимает
`WbMaximumClicks` только вместе с недельным лимитом), поэтому две
проверки роняют прогон, а не уезжают в кабинет: чужой тип стратегии и
отсутствие недельного лимита в ответе API. Тесты —
`scripts/seo/tests/test_direct_ceiling.py`.

## 10. Потолок цены клика отложен до 07.09

Через час после того, как решение о потолке было принято, выяснилось, что
корневая причина роста цены клика уже найдена и устранена другим контуром
(PR #372, применено 04.09 в 19:17 МСК): четыре группы расширения были
заведены без явного режима автотаргетинга, и Директ включил его в полном
виде — том самом, что отключали 29.08 и 31.08. Он тянул смежные услуги вне
оффера: «подключение к электронному документообороту стоимость» 42,37 ₽,
«финансовые услуги по оплате за границу» 40,70 ₽, «оплата зарубежных
сервисов из россии» 73,66 ₽ при 100 % отказов и 0 секунд на сайте.
Действие `ops-direct autotargeting` выровняло все группы на EXACT-only.

Решение руководителя 04.09: потолок не применять, дождаться замера
понедельника. Основания:

- цена клика выросла не «сама» — у роста есть объяснённая и уже
  устранённая причина, а потолок лечил бы следствие;
