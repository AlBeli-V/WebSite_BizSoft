# Sourcing and legal policy

Record provenance for every canonical asset.

## Source priority
1. Official brand/press/media kit.
2. Official product website/CDN.
3. Official documentation, app marketplace, or vendor-controlled repository.
4. Reputable secondary repository only as a fallback.

## Evidence to capture
- source_url
- source_domain
- source_type
- retrieved_at if available
- original_format
- official_or_secondary
- trademark/legal note

## Legal status values
Use concise machine-friendly values, for example:
- `official_brand_asset_subject_to_trademark_guidelines`
- `official_product_asset_subject_to_trademark_guidelines`
- `secondary_copy_trademark_owned_by_vendor`
- `user_supplied_asset_trademark_owned_by_vendor`

Do not claim a logo is public domain merely because it is downloadable. Logo/trademark rights usually remain with the owner.
