# Спорные вопросы: шаблоны диалога

Развилки, которые скил не решает сам. Формат один и тот же:
**что нашли → варианты → что рекомендую и почему → цена решения → жду ответа.**

Смысл не в вежливости, а в том, что эти решения меняют либо обязательство перед
покупателем, либо то, что видят все посетители сайта. Ошибиться тут дешевле на этапе
вопроса, чем на этапе отката.

---

## Заводить ли новый раздел каталога

```
Спорный вопрос · новый раздел каталога

Товары       ManageEngine ADManager Plus, ADAudit Plus, PAM360, Password Manager Pro,
             Access Manager Plus, Key Manager Plus + MSP-издания трёх из них
             — всего 741 позиция, из них 46 карточек

Почему не подходят существующие разделы
  security   «Антивирусы и безопасность» — про защиту периметра,
             а это управление учётными записями
  system     «Системное ПО и ОС» — про операционные системы и виртуализацию

Рекомендую   завести раздел  iam  «Учётные записи и доступ»
Почему       741 позиция и отдельное назначение; покупатель выбирает раздел по задаче,
             а не по вендору

Цена решения новая плитка на /catalog, новый пункт в меню «Назначение ПО»,
             новый URL в sitemap и переобход, иконка в CategoryIcon.astro,
             строка в ALLOWED_CATEGORIES, текст intro

Альтернатива сложить всё в security — раздел станет разнородным и перестанет
             отвечать своему названию

Ваш выбор: [завести iam] [сложить в security] [другое название] [обсудить границу]
```

## Какие товары класть в новый раздел

Отдельный вопрос — не сливай с предыдущим. Границу раздела почти всегда нужно
обсуждать отдельно от самого факта его создания.

```
Спорный вопрос · границы раздела endpoint «Рабочие места и устройства»

Предлагаю включить
  Endpoint Central, Patch Manager Plus, Mobile Device Manager Plus,
  Remote Access Plus, OS Deployer                              — 603 позиции

Спорные — это про защиту, а не про управление
  Vulnerability Manager Plus, Ransomware Protection Plus,
  Malware Protection Plus, Endpoint DLP Plus                   — 280 позиций
  предлагаю оставить здесь: это агентские инструменты на тех же рабочих местах,
  разнесение разорвало бы линейку вендора пополам
  альтернатива: перенести в security

Ваш выбор: [как предложено] [спорные — в security] [разобрать по одному]
```

## Enterprise-тариф с публичной ценой

```
Спорный вопрос · enterprise

Позиция      PAM360 Enterprise
Общее правило
             enterprise-тарифы не заводим: у большинства вендоров это значит
             «цены нет, обращайтесь в отдел продаж»
Здесь иначе  магазин вендора публикует цену и продаёт тем же самообслуживаемым
             checkout'ом; у PAM360 редакция Enterprise вообще единственная
Подтверждение
             цена со снимка магазина, снято 20.08.2026, снимок a91f0c22e4d1

Рекомендую   завести; послабление узкое — только позиции с подтверждённой снимком ценой
Цена решения исключение в tests/vendor-catalog.test.ts с комментарием об основании

Ваш выбор: [завести] [отклонить] [завести без цены]
```

## Цена с налогом или без

```
Спорный вопрос · НДС страны биллинга

Позиция      Sentry Team
На странице  «€26 / month, VAT included» — переключателя страны нет
Что это значит
             в цену вшит НДС Ирландии 23%; без него выходит €21.14
Рекомендую   записать цену без НДС: наценка не должна начисляться на чужой налог
Риск         если вендор выставит счёт с НДС, себестоимость окажется выше расчётной

Ваш выбор: [без НДС, 21.14] [как на странице, 26] [уточнить у поставщика]
```

## Вечная лицензия без парного сопровождения

```
Спорный вопрос · вечная лицензия без сопровождения

Позиция      OpManager Enterprise (Perpetual), $19 995 разово
Обычно       вечная лицензия продаётся парой с годовым контрактом сопровождения:
             обновления и техподдержка оплачиваются отдельно
Здесь        в колонке сопровождения стоит «Included» — отдельной строки прайса нет

Рекомендую   завести без парной позиции и указать в описании, что сопровождение
             первого года входит в цену
Риск         если «Included» относится только к первому году, на второй год покупателю
             понадобится контракт, которого у нас в каталоге нет

Ваш выбор: [завести без пары] [уточнить у вендора] [отклонить]
```

## Товар только «по запросу»

```
Спорный вопрос · позиция без публичной цены

Позиция      n8n Enterprise
На странице  «Contact us» — цены нет, checkout нет

Правило проекта
             quote-only тарифы не заводим вовсе, даже как «по запросу»

Но           у n8n это единственный тариф выше Starter, и без него линейка
             на витрине обрывается

Рекомендую   отклонить и записать причину; линейку обрывать не страшно —
             карточка без цены и без покупки не помогает покупателю
Альтернатива завести с пустой price: витрина покажет «Цена по запросу»,
             прямой покупки у такой карточки нет по построению

Ваш выбор: [отклонить] [завести с пустой ценой]
```

## Как вести диалог

- **Один вопрос за раз.** Список из шести развилок подряд читается как анкета,
  и отвечают на него формально.
- **Показывай цену решения.** Не «завести раздел?», а «завести раздел — и вот что
  за этим последует».
- **Всегда давай рекомендацию.** Вопрос без своего варианта перекладывает работу
  обратно на владельца.
- **Не додумывай при молчании.** Нет ответа — сделай всё, что от него не зависит,
  а спорный пункт вынеси отдельным списком в конце. «Пока заведу, потом поправим»
  превращается в незамеченную ошибку на проде.
- **Записывай решение.** Каждое принятое решение — строка в отчёте партии с датой,
  а если оно меняет правило — комментарий в тесте.
